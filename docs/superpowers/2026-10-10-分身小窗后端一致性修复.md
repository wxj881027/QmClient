# 分身小窗后端一致性修复

状态：代码修改与静态审阅完成；已补充测试，未执行。未编译、未运行 gate、未启动客户端。

## 已确认行为

OpenGL 与 Vulkan 的实时分身小窗使用相同的离屏画面、圆角形状和回贴方式。旧 OpenGL 上下文不支持离屏目标时，不显示实时小窗，显示“当前图形后端不支持分身小窗”提示。这一回退行为已由用户确认。

保留现有功能开关、跟随对象、缩放和自动隐藏规则，不增加图形设置。关闭功能释放目标；自动隐藏和缩小小窗时保留容量，恢复显示后复用。

## 修复内容

- HUD 不再使用 OpenGL 直接改写主视口的路径。两种后端都先绘制完整小窗，再按相同圆角几何回贴；纹理纵向坐标适配各后端原点。
- 地图分组裁剪共用屏幕到目标的坐标换算。先与屏幕范围相交，再向外取整缩放，保留细小裁剪区域。
- 回贴小窗时关闭混合，直接复制已经包含背景和半透明内容的颜色。修正现代 OpenGL 忽略 NONE 混合模式和 Vulkan NONE 管线仍开启混合的问题。
- 离屏绘制保存并恢复前端绘制状态。OpenGL 同时恢复 framebuffer、viewport、scissor 和实际清屏色，避免小窗状态影响后续 HUD 或下一帧清屏。
- 目标容量按 64 像素块增长，缩小和自动隐藏不重建。图形资源重置后丢弃旧句柄，避免销毁复用同一 ID 的新资源。
- 维护两条后端提示的 TOML 翻译，并重新生成运行时语言文件。

远端 master 在本轮期间合入 PR #364，已经增加与 RGBA 单采样目标兼容的 Vulkan 离屏管线。本次基于该提交继续修复，复用其管线创建、选择与失败处理，不重复增加另一套实现。

- OpenGL 2.x / 3.x 与 Vulkan 的方向、位置、圆角和半透明内容对比。
