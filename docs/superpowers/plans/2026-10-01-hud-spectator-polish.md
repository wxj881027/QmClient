## 实现结果

- 表情碰撞缓存不透明矩形中心，按旋转后的不透明区域收紧地图查询范围。屏外表情继续模拟，只跳过绘制；相邻同纹理表情合批，不改变绘制顺序、240 Hz 模拟步长和碰撞判定。
- 坐标、速度、角度面板采用官方单层黑色半透明背景，移除额外模糊和玻璃层，保留原信息布局。
- 新增 `qm_show_main_title`、`qm_show_dummy_title`，均默认开启。使用固定本体、分身连接 ID 判断名牌和聊天头衔；切换开关时重建聊天布局，保留原始头衔数据和在线同步。
- HJ 辅助卡片提供水中旁观实体虚化开关和透明度。保留 `qm_paused_spectator_fade`（默认关闭）及原透明度配置（默认 40%）；复用水域识别，岸上旁观实体不受影响，皮肤与名牌使用同一倍率。
- 服务器列表圆形箭头减小图标内边距；已知难度 0 至 5 均显示五颗星，未知难度保持空白。
- 设置分段行统一测量与渲染，字体至少 12 UI 单位、高度至少 24 UI 单位，同时更新嵌套布局。
- 新增 `qm_spectator_friends_first`，默认开启，在好友卡片提供开关；关闭时使用原玩家顺序并去掉好友分组。
- 快速练习在发出切换队伍请求前只准备本地状态，不再吞掉请求；旁观目标切换正常发送原有消息。
- HUD 变淡存在可确认的状态泄漏路径：表情在 HUD 前绘制，淡出颜色可能遗留给读取当前颜色的 HUD 容器；分身动作图标也会留下低透明度。相关绘制出口和 HUD 入口恢复白色。用户报告的所有触发场景仍未复现。
