# 客户端模块重构提示词索引

源码：`https://github.com/wxj881027/QmClient`。输出：`D:\QmClient_code\模块`。

共整理 **101 个功能模块**，每个模块一份独立中文 Markdown，可将整份内容交给后续开发助手使用。覆盖原生客户端、Qm 扩展、内置地图编辑器及客户端依赖的引擎；不包含独立服务端、主服务器、命令行开发工具或第三方库内部重构。

## 如何使用

选择一个模块，将整份提示词交给开发助手。文档要求先阅读源码并确认行为，再按测试驱动顺序补测试及实现；默认不执行编译验证。文件名和说明均使用中文，真实类名、配置名、协议名、C++ 语法及源码路径保留原标识以便准确定位。

当前源码包含传统客户端实现以及一批保留的 Qm 配置和独立辅助库。因此，“已有实现”表示存在可定位的现有实现，“局部实现”表示已有组件或辅助逻辑而完整用户流程仍需核实，“配置声明”表示按现有声明编写的恢复提示词，不能理解为当前已经可用。所有状态描述针对本次磁盘源码，不代表历史版本。

每份提示词包含当前边界、源码入口、功能契约、C++20 重构建议、性能与动画要求、易用性与语法安全、专属测试场景和执行步骤。C++23 及以后特性仅可在确认工具链和升级范围后选用。

## 依赖与使用顺序

涉及协议、快照和物理预测时，先锁定二进制格式及特征测试，再修改使用它们的渲染和操作模块。涉及界面时，先确认通用控件、输入焦点和配置契约，再处理具体页面；无需为单个功能强行重构整个界面基础。

媒体模块按来源发现、来源解析、时间轴状态、系统媒体展示的关系协作；语音沿音频和网络基础设施实现。地图编辑器以文档和历史操作为中心，图层、资源、包络和工作台分别修改。共享文件的归属用于查找，不表示允许整文件跨模块改动。

完整文件归属和全部 Qm 配置声明对应关系见[源码与配置覆盖清单](<D:/QmClient_code/模块/源码与配置覆盖清单.md>)。
