# 赞助者发言样式

状态：历史实现记录。2026-10-25 起暂时移除客户端柔光样式，并调整资料刷新通道，见文末后续调整；客户端改动尚未编译或运行验证。

## 行为

- 独立保存 `chat_style`：空串保持普通消息，`soft_glow` 保留原正文渐变并增加柔光，`platinum` 使用银色底和间歇扫光。
- 复用赞助者 profile、凭证、昵称绑定和在线租约，不按昵称或头衔文字猜测身份。
- 仅已认证赞助者可以选择并获得正文特效；普通玩家和单独的开发者身份不因此获得特效。
- 旧资料缺少字段时保持普通消息；旧客户端保存资料时不清空新字段；未知样式回退普通消息。
- 仅装饰正文。提及、队伍、私信、自定义颜色及表情消息保留现有信息表达。
- 消息收到时保存样式，避免玩家槽位复用改变旧消息；混合作者合并仅在样式一致时保留特效。
- 柔光优先复用高斯模糊接口，不支持时使用低强度偏移辉光；铂金不依赖模糊。
- 不增加外部材质；铂金高光按下方确认的节奏播放，柔光保持原行为。

## 铂金扫光调整

用户反馈原铂金高光不够突出；再次与 Gemini、Claude 讨论后，用户确认改为窄幅斜向扫光。

- 银色底降低最高亮度，为白色扫光保留对比；深色描边保持可读性。
- 新消息按排版后的行顺序从上到下扫过，每行从左向右持续 1 秒；上一行完成后立即进入下一行。
- 最新可见的、启用正文样式的赞助消息在整条扫完后停 1 秒，再从第一行重播；其他消息只完成到达时的首轮。
- 光带连续穿过字形内部；每次只覆盖当前行，自动换行和手动换行共用实际排版行范围。
- 打开聊天输入、查看历史记录或滚动回看时继续按相同节奏播放；HUD 编辑预览仍保持静态。
- 现有「赞助头衔」卡片的正文预览使用相同效果；切换样式时立即播放，预览恢复显示后按同样节奏重播。
- 保留 `platinum` 标识、赞助认证和同步方式，本次无需更新服务端或迁移兑换数据。

后续调整：用户在 PR #289 合并后要求缩短间隔、历史窗口继续播放并改为逐行扫光；以上行为已替换首版的七秒周期、历史静止与整段同时扫光。
