# V3 发布修复记录

本文记录正式标签创建前的修复和已有验证。正式版本为 `3`，开发版本保持 `3.13.1`。

## 启动校验表越界

完整构建的源码校验清单包含 1077 个文件和 22 条额外信息，超过 `CChecksumData::m_aFiles` 的 1024 项容量。旧生成器直接输出全部下标赋值，客户端启动时会写入结构体后面的内存。

生成器现在先生成常量表，再按目标数组容量复制。文件总数和额外信息总数保留原值，结构体大小及已有有效项的顺序不变。这与命令校验表现有的容量处理方式一致。

新增回归测试直接调用生成的生产方法，检查数组之后的哨兵数据。修复前该测试失败，修复后通过。

## 发布与资源检查

- 标签校验复用 `bump_version.py`，允许当前正式版本使用 `v3`。
- clang-tidy 可选特性构建中的注释移到命令之前，避免截断 Bash 续行。
- Windows 本地 clang-tidy 使用 `/Y-` 解析头文件，避免加载 MSVC 专用预编译头。
- 117 张普通 PNG 使用仓库工具完成透明像素扩边。逐像素比较确认 alpha 和所有非透明像素的 RGB 未变。
- 5 张距离场图集保持原数据，检查器通过已有 JSON 元数据识别此类资源。
- 进程测试识别现有的中英文完赛消息；启动收藏场景显式启用其断言所需的日志级别。
- 更新设置卡片页签的过时预期，清理失效的源码断言，并补充名牌边距和同名不同配色皮肤的行为测试。
