# 测试目录整理与清理实施记录

状态：两轮清理与本轮验证完成。日期：2026-10-01。

本轮整理现有 C++ 测试目录、清理确认无效的测试入口，并修正库存工具。生产运行时逻辑、测试名、协议和数据格式不在本轮修改范围内。其他任务的改动继续保留。

## 目录与构建

测试分入 `src/test/unit/`、`integration/`、`contract/`、`mixed/` 和 `support/`，层级内按功能域组织，`benchmark/` 保留独立入口。`test.cpp`、`test.h` 保留顶层。整理期间曾暂留并发任务修改的 `QmAnimDropdownTest.cpp`；现已迁入 `unit/qmclient/ui/`，同步更新公共头文件引用和构建注册。

根 CMake 测试清单改为显式完整路径，所有测试目标、辅助源文件和 benchmark 的相关引用一并更新。公共辅助头改用 `test/support/` 引用，include guard 同步采用路径名称。

- 删除只剩注释的 `qm_ui_scale_popup_contract_test.cpp`、`voice_qmclient_contract_test.cpp` 及其注册。

- 删除未注册的 `qm_axiom_probe_test.cpp`：主要输出 JSON 解析调试过程，最终生产解析结果没有断言；实际解析由现有 Axiom 分数测试验证。
- 清理未注册的 `render_target_test.cpp`：其中 8 项命令合并行为迁入 `unit/engine/graphics/graphics_command_batch_test.cpp` 并注册，其余为已迁出的测试或源码字符串影子断言。不恢复那些只验证实现写法的断言。
- 清理未注册的 `QmIconAtlasTest.cpp`：旧 alpha 图集与 probe 机制已移除，MSDF 策略和资源约束由现有注册测试保护；缺少的颜色迁移行为拆成 4 项生产接口测试，诊断窗口的 2 项现行行为从合同文件迁入单元目录。

- 补注册 `qm_friend_online_tracker_test.cpp` 的 15 项真实状态机测试。

第一轮暂保留的 `qmclient_monitoring_test.cpp` 已在第二轮完成逐功能核对并删除；507 项遗留声明的处理依据见下文。

补注册尝试暴露 `QmDiscreteSliderStyleTest.cpp` 依赖被替代的 `UiDiscreteSliderStyle.h`：旧头与 `UiDiscreteSliderLogic.cpp` 重复定义函数，链接失败。现行 `QmDiscreteSliderTest.cpp` 已覆盖颜色、档位、粒子边界与无效尺寸，故删除旧测试及其注册。进一步核对发现旧头仍由生产 `UiForms.cpp` 使用，因此保留生产头及其注册，不接管并发任务的 UI 迁移。

独立 `qm-nmt-tests` 目标的实际构建发现原清单列入了 QQ 音乐、酷狗与配置注册测试，却未链接协议生产实现与 `g_Config` 存储。已补齐两个生产源文件，并用仅链接到独立目标的 `support/music_config_test_support.cpp` 提供真实 `CConfig` 对象，不复制配置算法。`run_cxx_tests` 在音乐目标存在时一并构建并执行它，避免日常 gate 漏掉独立入口。
