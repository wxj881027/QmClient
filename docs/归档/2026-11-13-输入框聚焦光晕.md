# 输入框聚焦光晕

日期：2026-11-13
状态：已实施（未提交）

## 目标

聚焦中的输入框在外壳描边之外有一圈淡淡的强调色光。光晕是「这个框正在接收输入」的第二重提示，描边仍是主提示。光晕只跟着焦点走，不跟着控件类型走。

## 行为

- 判定与焦点描边共用同一处：`ui_widget::InputFieldFocusActive` 与 `ui_token::motion::INPUT_FOCUS_RING` 淡入轨道。聚焦淡入多少，光晕就亮多少，不另开动画轨道。
- 三种模式（TEXT / SEARCH / MULTILINE）行为一致。服务器筛选卡里搜索框、排除框、服务器地址框并排时，点哪个框哪个框亮，其余框暗。
- 失焦沿同一条轨道单向变暗，淡出结束不再提交光晕绘制。
- 光晕画在外壳之前。光晕最亮处贴外壳边缘，外壳随后盖住内侧那一半，留下的是从边缘向外散开的光。
- 浅色表面按表面亮度压暗，最亮表面只留 55% 强度（`ResolveUiSurfaceGlowScale`），深色主题几乎不变。

## 实现安排

- `src/game/client/QmUi/UiSurface.h`、`src/game/client/QmUi/UiSurface.cpp`
  `SRoundedGlowParams` 与 `DrawRoundedSurfaceGlow` 三个重载。有圆角 SDF 时走「只描边 + 带宽羽化 + 形状外扩」：一条连续衰减带，带宽内按幂次淡出。无 SDF 时退回三道逐层变淡的一像素窄环，只近似。
- `src/game/client/QmUi/UiTokens.h`
  `ui_token::glow` 集中放宽度比例、上下限、内外层比例、衰减指数、强度、表面压暗与裁剪放行距离。宽度 = clamp(外壳高 × 0.20, 2.5, 5)。
- `src/game/client/QmUi/UiForms.h`
  `SInputFocusGlowLayer` 与 `ResolveInputFocusGlowLayers(ShellRect, FocusAlpha, Enabled)`：外层宽而淡（0.12）、内层窄而亮（0.22）；进度夹到 0..1，非法矩形不产生层；`Enabled` 为 false 时返回两层全零。
- `src/game/client/QmUi/UiForms.cpp`
  `InputField` 在外壳之前绘制两层光晕。颜色取 `SUiTheme::m_FocusRing`，再乘 `ScaleControlAlpha` 与表面压暗系数。开关读 `g_Config.m_QmUiFocusGlow`。
- `src/game/client/QmUi/SettingsCard.h`
  `ResolveSettingsFocusSafeClipRect` 额外放行 `ui_token::glow::FOCUS_CLIP_ALLOWANCE` 像素，避免卡片内容裁剪把光晕切成直边；外扩后仍与卡片矩形取交集。

## 开关

- 配置项：`qm_ui_focus_glow`（`QmUiFocusGlow`，默认 1，范围 0..1），声明在 `src/engine/shared/config_variables_qmclient.h`。
- 设置位置：图像 → 视觉效果 → 界面主题卡，紧跟在「启用背景模糊」之后。行 id 为 `graphics-focus-glow`。
- 行为：只关光晕，不关焦点描边与文本焦点。开关实时生效，下一帧即改绘制。
- 搜索索引：`src/game/client/QmUi/cards/QmCardSearch/QmCardCatalogGraphics.inc` 增加标签与配置名。卡片关键词表 `src/game/client/QmUi/QmCardRegistry.cpp` 增加中英文关键词。
- 译文：`Enable focus glow` 与配置说明 `Show an accent glow around the focused input field` 已写入 12 种语言的 TOML，并重新生成 `data/languages/*.txt`。

## 不覆盖

- 控制台 `Ctrl+F` 搜索与 `DoClearableEditBox` 是另一条绘制链，没有光晕。
- 侧面面板（`SecondaryPanel`）里的输入框走 `InputField`，行为一致，未单独验收。
- 真实 GPU 像素证据未采。像素级「边缘最亮、向外单调变淡」目前只有设备边界的参数断言（`CQmRoundedSurfaceRender.SdfGlowIsBorderOnlyAndBandExpandsOutsideTheShell`），观感需人工验收。

## 验证

- 单元：`InputFocusGlow.*`（层表、宽度夹取、进度夹取、非法矩形、浅色表面压暗）与 `CQmRoundedSurfaceRender.SdfGlowIsBorderOnlyAndBandExpandsOutsideTheShell`、`CQmRoundedSurfaceRender.GlowWithoutSdfFallsBackToOutwardFadingRings`。
- 集成：`CInputFocusGlow.*`（真实 CUi + 文字引擎 + 动画运行时，真实点击驱动焦点）验证「聚焦的框提交内外两层光晕」「三种模式行为一致」「失焦单向淡出」「同一张卡片里只有被点的框亮」「关掉开关后光晕消失、焦点描边仍在」。
- 未采行/分支覆盖率，不声称覆盖率数字。
