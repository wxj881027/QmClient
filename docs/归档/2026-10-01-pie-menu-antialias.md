## Claude 设计与落地选择

- 已通过本机 Claude CLI 咨询并追问校正，原始回复保存在 `tmp/claude-pie-menu-design-20261001.json`、`tmp/claude-pie-menu-design-final-20261001.json`。
- 采用现有配色与图标布局，悬停只改变颜色，固定扇区半径、图标与文字位置及字号。
- 内外圆弧、径向边、角点、中心圆统一使用透明度羽化。角点共享边界顶点，避免重复叠色。
- 游戏内主环、改名环和设置预览共用 `QmUi` 绘制辅助。
- 不改变游戏内命中半径、选项顺序、数字键、按住松开执行方式、0.08 秒动画及 `MenuScale()`。
- 保留并兼容其他任务新增的“复制名字”和单项完整圆环；完整圆环不产生径向接缝。

Claude 回复中的数值和 API 按当前源码校正：

- 每扇区原有 24 段，并非整圆 24 段；动态分段按 `R * (1 - cos(step / 2)) <= 0.2px` 求解，上限 256 段，中心圆也按同一误差计算。
- 羽化宽度为 1.5 帧缓冲像素，通过 `GetScreen()` 与 `ScreenSize()` 换算。密集扇区缩窄羽化以保留间隙。
- 不采用相邻扇区重叠、增加调试配置或固定段数中心圆的建议。
- 悬停保持原有亮度与 alpha 乘法，配置 alpha 为零时仍然透明；不采用可能使透明选项重新显色的固定 alpha 增量。
