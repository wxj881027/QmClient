## 变更说明

新版界面的二级菜单、下拉按钮和标题栏原先由多个调用点各自管理，导致 default 国旗无法选择、弹层遮罩覆盖设置页面、关闭按钮比例与配色不一致。当前改为共用二级面板外壳和图标按钮几何，把背景与焦点颜色统一放进图形设置的视觉效果卡片，并明确区分按钮、输入框表面和展开列表表面。

工作区还包含字体与名牌缓存修正、快捷键失焦处理、轮盘和通知动效、贡献者子页签，以及测试目录迁移和库存门禁。客户端 input.cpp 与 binds 的改动涉及按键事件、失焦释放及展示面板；没有把这些交互改动隐去为纯 UI 样式修改。本轮确认问题的修复与剩余验证边界见文末。条件设置行统一通过公共行流参与绘制和测量，隐藏自定义文本颜色时不再占用卡片高度。

## 改动内容

### feat

- 新增公共控件背景颜色与透明度，沿用 qm_ui_dropdown_* 存档键；视觉效果卡片以“按钮、输入框背景颜色”和“二级菜单、展开列表背景颜色”明确控制范围，普通按钮、下拉触发器与输入框复用同一表面角色。
- 字体商店、玩家国旗、浏览器国旗和翻译设置共用标题栏、正方形关闭按钮及公共面板属性；字体商店增加标题栏。
- 国旗弹窗增加搜索、自适应列数与更紧凑图标；大型面板尺寸沿用字体商店的视口策略。

### fix

- default 国旗的合法代码 -1 可以提交；无效选择不会覆盖玩家国家设置。
- 全屏遮罩不再重画先前缓存的菜单背景，保留原设置页面作为底层；关闭弹层模糊时阻止半透明绘制绕过开关。
- 纯图标按钮背景、图标与点击区域使用同一套居中正方形几何。
- 文字容器关联字形图集 revision；字体和图集变化后让旧容器失效，回收资源并保护复制句柄。
- 名牌和普通字形使用独立缓存 profile；临时字体商店预览不改变全局字体角色。
- 截图组合键在计分板和旁观输入中继续下传，失焦时区分展示面板与真实玩家输入；翻译按钮和语言选择使用共享行为接口。

### refactor

- 删除深色玻璃配置和颜色覆盖分支，移除表面隐式光照提亮及二级菜单压暗，颜色与独立透明度由公共配置直接解析。

- C++ 测试按 unit、integration、contract 与 support 归位，更新 CMake 注册；清理失效或重复合同，保留真实行为测试。
