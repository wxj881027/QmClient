## 两套隔离配置

配置种子放在 `qmclient_scripts/integration/fixtures/default_profiles/`：

| 配置 | 内容 | 准备方式 |
| --- | --- | --- |
| `default.cfg` | 当前声明的全部默认值，不自动应用推荐外观 | 复制到新的隔离目录 `qmclient/settings.cfg` |
| `recommended.cfg` | 推荐外观，字体缺失时保留默认字体与字重 | 复制到另一隔离目录 `qmclient/settings.cfg` |

每次回归使用新的目录，不覆盖之前的证据。Windows 的隔离开发构建需要 `DEV=ON、QMCLIENT_TEST_STORAGE=ON`，通过 `QMCLIENT_TEST_STORAGE_ROOT` 选择配置根；普通发布客户端忽略 `storage.cfg`，不能用它隔离玩家配置。便携包的发布验收使用工作区 `tmp/` 内的独立副本和程序旁 `profile/`。具体入口见[进程级测试说明](../../qmclient_scripts/integration/README.md)。

首次启动路径另用完全空目录检查，确认不会误判为历史配置。推荐预设还需要两个独立场景：不安装 LXGW WenKai 时应用后保持原字体；字体资源可用时通过卡片应用，再保存、重启检查。推荐种子不能替代“点击应用”的交互验证。

## 固定尺寸

两套配置分别在以下九种尺寸检查：

| 比例 | 分辨率 |
| --- | --- |
| 16:9 | 1280×720、1366×768、1920×1080、2560×1440、3840×2160 |
| 5:4 | 1280×1024 |
| 4:3 | 1600×1200 |
| 16:10 | 1920×1200 |
| 21:9 | 2560×1080 |

再以 1920×1080 检查 UI 125%、150%、200%，以及系统高 DPI 窗口。中文和英文各检查一次；长标题、长说明和长候选词不得遮挡操作区。

每个尺寸都检查服务器列表、设置、聊天、IME、饼菜单和 HUD 编辑器。空间不足时应减列或滚动，按钮必须可达。保存截图时记录实际窗口像素、系统缩放和客户端 UI 缩放，不能只记显示器分辨率。
