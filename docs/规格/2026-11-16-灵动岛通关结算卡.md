# 灵动岛通关结算卡

状态为已实现，运行与视觉验收待完成。

## 使用与展示

在 Qm 设置的灵动岛卡片启用“显示结算卡”，也可以搜索“结算卡”进入同一张可交互设置卡。配置为 `qm_finish_summary`，默认关闭。启用后，在 DDNet 官方服、Axiom Gores 和 AXRace 服通关时展示当前操控角色的成绩。

主岛保留时间、媒体和附岛内容，结算卡从其下方生长分离，结束后先向主岛收窄上缘，再带动下缘向上收回。分离时主岛外壳收缩，合并时轻微膨胀。独立歌词显示在结算卡下方。卡片按上一版的 1.5 倍放大，宽度上限为游戏窗口的 37.5%，高度上限为 30%，HUD 缩放和窗口边界参与布局。内容沿用 480×216 的比例，保留地图名、作者、类型、星级、完成日期、个人成绩对比、排名、玩家、类型完成进度及总分变化。玩家昵称旁展示通关时使用的 Tee。作者名紧接地图名的最后一行，右对齐。用时与有效排名数字带荧光，星级从左至右逐颗出现。

通关用时随卡片生长在中央出现，再移动到左上角，地图名、用时和排名数字逐渐放大，两条分隔线从中央向两端展开。数值从零递增至目标值，计数过程带颜色变化和字形内部渐变，后续网页数据到达时从当前显示值接续变化。关闭 UI 动效时直接显示完整结果，重新开启不会重播已经结束的入场。

角色移动只驱动双轴倾斜，停止时回正。移动和静止时卡片的可见度一致。关闭 UI 动效会停用倾斜和收放形变。完整展开后，收回过渡约 0.48 秒，上缘先吸附岛口，宽的下缘随后收拢。支持离屏目标时，收回期间复用最后绘好的卡面，使文字和地图封面沿同一轮廓变形。

DDNet 封面取自现有地图元数据中的官方缩略图，与投票地图库共用下载、磁盘及纹理缓存。地图封面等比居中铺满整张卡片。以左边中点为中心做径向模糊，原图与模糊图的混合比例从左端 10% 线性过渡到右端 80%。仅处理图片，不叠加黑色蒙版。展开后封面和用时计数共用同一进度，约 0.55 秒内从透明变为完全可见。关闭动效时直接显示。地图资料到达即预取封面；迟到的贴图从当时的计数进度显示。完整封面缓存尺寸为 512×256，最多驻留两张。Axiom 当前地图接口没有封面字段，缺图时使用背景色。

分离后的卡片将背景、文字和 Tee 合成到一个复用离屏目标，再统一倾斜。目标内部采用实底合成，有可用模糊底图时先铺底图，再叠背景色。连接阶段直接绘制内容，由主岛与结算卡共用的 SDF 表面负责融合。此路径复用现有渲染目标和纹理管线。

完成日期采用客户端本地时间，精确到分钟。通关用时显示厘秒，超过一小时显示小时。个人成绩与通关前个人最佳比较，区分首通、个人最佳、进步、持平、退步和历史未知。用时缩短显示负号，用时增加显示正号。

卡片内容呈现完成后停留 12 秒，再恢复当前灵动岛内容。音乐与歌词状态持续更新。重复通关消息合并到同一次结算。右上角通关消息列表隐藏当前角色同一次通关的重复提示，其他玩家消息按原规则展示。重新起跑、换图、断线、切换操控角色或关闭功能会结束当前展示。原版灵动岛样式、隐藏 HUD 和 rank 回放模式下停用结算卡。同一设置卡的“预览结算卡”是一次性开关，回到游戏后播放。本次连接在当前地图有通关就重播最近一场，否则取当前角色的地图个人最佳。两者都没有时不显示。切换地图、连接或操控角色后清除上一份成绩。

## 数据口径

| 内容 | 来源及含义 |
| --- | --- |
| 本服排名 | 通关时在线且具有服务端完整成绩资料的玩家个人最佳，同名合并，并列采用 1、1、3 排序。分母为有通关成绩的人数，资料不全时显示暂无数据。 |
| DDNet 全球排名 | 官方玩家 JSON 中当前地图的个人排名。 |
| DDNet 国服排名 | 官方地图 JSON 的 CHN 榜单。接口只返回前 20 项，榜外显示暂无数据。 |
| Axiom 排名 | Gores 或 AXRace 地图榜按账号匹配，替代国服与全球两行。当前公开身份接口没有角色 ID，采用前 200 项地图榜，榜外显示暂无数据。 |
| 完成进度 | 当前地图类型的已完成地图数与目录总数。 |
| 总分增加 | 这张地图首次给相应身份带来的地图分值，重复通关为 +0。Axiom 按账号核对首次完成，显示的玩家名称仍为当前操控角色。 |

地图、玩家、模式和账号响应均核对请求身份。网页成绩未同步时保留旧数值，卡片不显示“上次同步”小字。缺少当前值时区分加载中、等待同步和暂无数据。首次积分增加需要通关前历史与通关后记录共同确认，历史未知时不推算增分。

查询在后台使用公开 HTTP 接口。每次连接上下文预取基线，通关后刷新。请求间隔至少 0.5 秒，每项最多两次，并遵守 Retry-After。卡片关闭或上下文改变后取消请求，迟到解析结果按请求代次隔离。

## 实现与验证

业务组件位于 `src/game/client/components/qmclient/finish_summary.*`，解析与结算计算位于 `finish_summary_data.*`，展示生命周期位于 `finish_summary_state.h`。卡片渲染位于 `src/game/client/QmUi/QmFinishSummary.*`，HUD 负责主岛形变、附岛位置与内容切换。设置复用灵动岛全局卡片及搜索注册。

初版在 `09e45a60b8` 上完成 Windows Release 构建。玩家提供的通关截图确认卡片能出现，同时发现尺寸、重复通关提示和差值符号问题。上一轮已调整这些行为，核对了简体中文产物，并补充成绩解析、消息去重、展示时长、布局和数字入场测试。

已补充测试，未执行。覆盖封面在卡片两侧的裁切、模糊强度与颜色保留、收回起点连续性、岛口与下缘的先后顺序，以及星级延迟到达后的入场。实际游戏中的荧光可读性、收回观感和帧耗时仍待确认。
