# 灵动岛通关结算卡

状态为已实现，运行与视觉验收待完成。

## 使用与展示

在 Qm 设置的灵动岛卡片启用“显示结算卡”，也可以搜索“结算卡”进入同一张可交互设置卡。配置为 `qm_finish_summary`，默认关闭。启用后，在 DDNet 官方服、Axiom Gores 和 AXRace 服通关时展示当前操控角色的成绩。

主岛向下展开为圆角半透明卡片，沿用灵动岛背景、模糊与 HUD 编辑器位置。卡片实际宽度最多为游戏窗口宽度的四分之一，高度最多为窗口高度的五分之一，HUD 编辑器放大后仍遵守上限。内容采用 480×216 的比例布局，保留地图名、作者、类型、星级、完成日期、个人成绩对比、排名、玩家、类型完成进度及总分变化。玩家昵称旁展示通关时使用的 Tee。

通关用时先在卡片中央出现，再移动到左上角，其他信息依次显现。数值从零递增至目标值，后续网页数据到达时从当前显示值接续变化。关闭 UI 动效时直接显示完整结果，重新开启不会重播已经结束的入场。

完成日期采用客户端本地时间，精确到分钟。通关用时显示厘秒，超过一小时显示小时。个人成绩与通关前个人最佳比较，区分首通、个人最佳、进步、持平、退步和历史未知。用时缩短显示负号，用时增加显示正号。

卡片内容呈现完成后停留 12 秒，再恢复当前灵动岛内容。音乐与歌词状态持续更新。重复通关消息合并到同一次结算。右上角通关消息列表隐藏当前角色同一次通关的重复提示，其他玩家消息按原规则展示。重新起跑、换图、断线、切换操控角色或关闭功能会结束当前展示。原版灵动岛样式、隐藏 HUD 和 rank 回放模式下停用结算卡。当前版本没有历史记录和回看入口。

## 数据口径

| 内容 | 来源及含义 |
| --- | --- |
| 本服排名 | 通关时在线且具有服务端完整成绩资料的玩家个人最佳，同名合并，并列采用 1、1、3 排序。分母为有通关成绩的人数，资料不全时显示暂无数据。 |
| DDNet 全球排名 | 官方玩家 JSON 中当前地图的个人排名。 |
| DDNet 国服排名 | 官方地图 JSON 的 CHN 榜单。接口只返回前 20 项，榜外显示暂无数据。 |
| Axiom 排名 | Gores 或 AXRace 地图榜按账号匹配，替代国服与全球两行。当前公开身份接口没有角色 ID，采用前 200 项地图榜，榜外显示暂无数据。 |
| 完成进度 | 当前地图类型的已完成地图数与目录总数。 |
| 总分增加 | 这张地图首次给相应身份带来的地图分值，重复通关为 +0。Axiom 按账号核对首次完成，显示的玩家名称仍为当前操控角色。 |

地图、玩家、模式和账号响应均核对请求身份。网页成绩未同步时保留旧数值，卡片不显示“上次同步”小字。缺少当前值时区分加载中、等待同步和暂无数据。首次积分增加需要通关前历史与通关后记录共同确认，历史未知时不推算增分。

查询在后台使用公开 HTTP 接口。每次连接上下文预取基线，通关后刷新。请求间隔至少 0.5 秒，每项最多两次，并遵守 Retry-After。卡片关闭或上下文改变后取消请求，迟到解析结果按请求代次隔离。

## 实现与验证

业务组件位于 `src/game/client/components/qmclient/finish_summary.*`，解析与结算计算位于 `finish_summary_data.*`，展示生命周期位于 `finish_summary_state.h`。卡片渲染位于 `src/game/client/QmUi/QmFinishSummary.*`，HUD 负责主岛形变、附岛位置与内容切换。设置复用灵动岛全局卡片及搜索注册。

已补充解析、成绩比较、本服并列排名、积分同步、去重、重新起跑、展示时长和几何布局测试，并更新设置卡高度测试。本轮追加通关消息匹配、屏幕尺寸上限、HUD 缩放和内容动效测试。已补充测试，未执行。

初版在 `09e45a60b8` 上完成 Windows Release 客户端构建。用户提供的实际通关截图确认卡片能够出现，同时发现卡片过大、右上角重复通关提示及差值符号问题。本轮按该反馈调整，修订后的 Windows Release 客户端已通过 `qmclient_scripts/cmake-windows.cmd --build cmake-build-release --target game-client -j 6` 构建。测试注册库存、修改文件的格式检查与 `git diff --check` 通过，简中产物已核对。运行时动画及最终视觉效果尚待实机验收。
