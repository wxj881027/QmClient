# 扩充赞助者动态头衔设计方案

根据需求，将现有的 Moon/Sun 体系扩充，并为所有头衔引入动态视觉动效。

## 1. 新增头衔类型
在现有的 `EQmTitleBadgeStyle` 枚举中增加 Earth, Morning Star, Black Hole。

### 设计表现：
- **Earth**: 以青蓝色系为基调，几何图案表现地球的经纬线网格。动效：缓慢平移的经纬线。
- **Morning Star**: 以璀璨的晨星光芒（黄色/白色）为基调。动效：中心发散的脉冲闪烁（亮度/缩放变化）。
- **Black Hole**: 以深邃的紫黑色为基调，周围环绕事件视界圆环。动效：圆环的旋转与中心引力吸入式的粒子闪烁（向内缩放的几何点）。

## 2. 动态效果实现逻辑
现有渲染体系依托 `CQmTitleBadge::RenderSurface` 和网格图案（Geometry）。
- **动态更新**: 将 `SQmTitleAppearance` 扩展或利用已有的 `m_Style` 结合渲染时间进行偏移采样。
- **几何网格**: 复用 `CQmBadgeGeometry` 体系，为三种新头衔添加对应的几何组件。

## 3. 实现计划
1. **枚举定义**: 更新 `src/game/client/components/qmclient/qm_title_appearance.h`。
2. **几何资源生成**: 运行 `qmclient_scripts/generate_badge_geometry.py` 生成新的 SVG 及转换后的几何网格数据。
3. **渲染逻辑更新**: 在 `CQmTitleBadge` 的 `RenderSurface` 和相关样式采样中引入对应动效。
4. **配置与国际化**: 更新配置文件和语言文件。

## 4. 验证计划
- 确保新增头衔的缩放与居中符合既定 `QmTitleBadge` 规范。
- 验证动效平滑度，避免帧抖动。
- 检查新头衔在聊天栏、名牌及预览卡片中的表现。

请用户确认以上方案是否符合预期。
