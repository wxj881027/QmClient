# 跨服跟随

好友列表、玩家列表、饼菜单和控制台共用 `CCrossServerFollow`。单次客户端会话只跟随一个玩家。在线好友可直接跟进好友行显示的服务器，离线好友可先开启跟随。控制台支持 `qm_follow <name> [clan]` 和 `qm_stop_follow`，旧的 `qm_pie_menu_stop_follow` 仍可停止跟随。

## 何时切服

- 首次找到目标时直接连接。实时快照确认双方同服后，目标转到其他服务器才应用 `qm_friend_auto_follow_delay`，默认 3 秒。倒计时中目标回到当前服，或名单暂时找不到目标时，取消这一跳并继续跟随。
- 服务器按 IP 和端口识别。同一服务器的 IPv4、IPv6 等地址由浏览器名单关联。当前服始终以实时快照为准。其余候选优先匹配姓名和战队，战队匹配无结果时只接受名单里唯一的同名玩家。启用忽略战队后按姓名匹配。
- 多个服务器有匹配项时，唯一的新服务器优先于最近确认的旧服。客户端最多暂时排除各离开的服务器 30 秒。名单中已无目标或实时快照确认目标回到该服时，提前结束排除。
- 满员时等空位。密码服提示手动连接，输入密码后可继续跟随。连接失败后，同一目的地至少等待 6 秒再重试。遇到密码拒绝时等待手动处理。

## 运行位置

`CCrossServerFollowEngine` 接收名单、快照匹配结果和时间，返回等待、提示或连接动作。`CCrossServerFollow` 每 0.5 秒检查一次，跟随期间每 5 至 10 秒请求刷新，扫描时使用当下可用的 HTTP 名单。HTTP 名单为空时读取浏览器当前列表，回放期间暂停切服。

手动断开或连接到其他服务器时结束跟随。自动跳转使用一次性连接护栏，网络掉线保留跟随，并由跟随组件接管重试。跟随目标只保留在内存中，旧的 `qm_pie_follow_name` 和 `qm_pie_follow_clan` 不再注册为配置项。
