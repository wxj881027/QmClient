- 数量是测试宏/函数声明，不展开参数化和类型化实例；CMake 注册包含条件分支及独立目标，不等于本机实际执行数。

- 文件行数只包括有测试声明的 C++ 文件，排除公共入口、支持编译单元和 benchmark；保留版权、注释及空行。
- 旧分类与新分类的占比变化不能直接称为删除效果；文件夹重组也不等于行为覆盖提升。
- 没有生成 line/function/branch coverage 报告，不提供代码覆盖百分比。Python、进程冒烟和端到端仅作库存，必须实际执行才称通过。
