# 本地控制台外观与设置

状态：已实现，待编译和游戏内验收。延续已合入 PR #339 的游戏内 F1 控制台。

- 被筛掉的分类按钮显示禁用图标，启用分类不显示。固定预留图标位置；「全部」恢复所有分类。
- 默认采用现代终端深色底、浅色文字。设置提供经典 PowerShell 和自定义配色，配置保存到现有客户端配置中；切换预设保留自定义颜色。
- 命令名、参数、数字、双引号字符串在输入行和真实命令回显中着色。显示层不改变命令执行；搜索不做语法高亮，搜索命中优先于链接和命令颜色。
- 顶部「控制台设置」打开面板。字号默认为 10，可调 8–24；背景不透明度默认为 96%，可调 20–100%；命令高亮默认开启，可关闭。
- 自定义配色覆盖背景、正文、命令、参数、字符串、数字、链接、搜索命中和当前命中；面板有预览和恢复默认入口。
- 面板与全局设置卡片使用同一内容实现和配置来源。调整立即生效；字号变化重算日志布局、搜索位置和点击区域。
- 面板打开时不执行控制台输入，不触发底层筛选、链接或滚动。Esc 先关闭子面板，关闭后恢复命令输入；关闭或切换控制台时关闭面板。
