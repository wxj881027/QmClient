## 3. 缺口与建议（按优先级）

### P1 · 服务器浏览器全界面零动效轨道——排序/筛选是最大的因果断点

**证据**：`menus_browser.cpp` 对 `QmAnimationRuntime / RequestAnimation / EUiAnimProperty / SUiSpringConfig / ResolveUiAnimValue` 的引用计数为 **0**。点击列头排序、修改筛选条件后，行内容逐帧硬跳到新位置；拖拽换列提交后被换位的列同样硬切。

**问题本质**：行不是「移动到新位置」而是「被替换」——正是 onetake 判定的 slideshow 特征（beats replace each other）。浏览器是使用频率最高的界面，排序/筛选是其最高频状态转换，此断点的体感权重最大。

**建议**：批二 FLIP 基建落地时，**首个应用场景改为服务器列表排序/筛选**（原定皮肤队列降为第二），复用既有 `CARD_REORDER` 弹簧；拖拽换列提交后同用 FLIP 让被让位的列滑入新槽位（虚影→落位形成完整因果链）。节奏规范：排序 FLIP 用单弹簧、不做逐行 stagger（stagger 属入场语言）、落定后完全静止（RestEpsilon 吸附）；表头与列宽（大 ground）不得参与动画。

### P2 · 灵动岛连接质量图标状态硬切换

**证据**：`hud.cpp:5052/5082` 直接以当前档位的纯函数结果绘制图标与颜色，HIGH→MEDIUM→LOW 变化时字形与颜色单帧硬换。

**问题本质**：网络劣化本身是渐变过程，图标却阶跃突变——状态切换没有衔接（onetake：上一个状态的某个量应存活到下一个状态）。

**建议**：档位切换时旧/新字形交叉淡出约 0.16s（交互级 token）、颜色同步插值（白→琥珀为注意力渐升，应渐变不应阶跃）；LOW 持续期间可加低频呼吸（报警语义，动效等级门控，恢复 HIGH 即静止——静止是呼吸生效的前提）。实现上每岛一组 ALPHA 轨道或对档位序号做一条 tween 轨道即可，注意双份渲染路径（5052/5082 两处）同口径。此项同时收敛 Gemini 维度四「网络健康感知」的警示诉求。

### P3 · 地图预览二级面板的来源线索 + 骨架屏流光（合并项）

**证据**：预览面板走 `ResolveSettingsSecondaryPanelRect` 居中 + `SecondaryPanelProperties()`（fade + 8px 上浮），触发点在列表行内的预览图标——效果（居中大面板）与原因（哪一行）视觉断连。且首开存在 100~300ms 同步解码空窗（审查已记录），面板出现后短暂空白。

**建议**：不做锚定展开（与字体商店既定模式冲突，收益低），改为**触发图标短暂高亮/选中态**让视线可回溯；同时按 Gemini 维度一给占位区加自左向右的浅色渐变光带（Wave Shimmer），告知异步加载中、消除「无响应」疑虑——shimmer 仅在加载期间存在，加载完成即静止。两件事共享「预览面板打开体验」一个场景，合并实施。

### P4 · 批二 FLIP 落地时的节奏红线（防呆）

FLIP 编排原语进入引擎后，把以下约束写进批四审计：排序类重排禁用逐行 stagger；动画结束必须完全静止（防微漂移）；大 ground（表头/列宽/滚动条）排除在 FLIP 之外。

### P5 · 参数化弹簧的 UX 论据（批一已落地，论据留档）

批一 FromResponse 构造器落地后，新 token 应以 Response/DampingRatio 表达（如「导航层一律 0.25s response」），材质关系可读，这也是批四审计识别离群手写弹簧的前提。存量 6 组物理量 token（NAVIGATION ζ≈0.93 / TOGGLE / SLIDER ζ≈0.70 / SLIDER_KNOB / CARD_REORDER / TWITCH ζ≈1.0）不强改数值防手感漂移，逐步补 Response 等价注释。

### P6 · 批三 PB 通关微仪式的概念约束（提前定调）

Gemini 方案的「勋章弹入 + 光晕渐隐」若直接实施，踩 onetake 两条硬规则：无粒子/彩屑（读作模板）；爆发后必须有静止。概念定为**「一个元素贯穿全场」：仪式从灵动岛胶囊中生长出来**——胶囊展开 → 勋章弹出（squash 落定，无彩屑）→ 提升时间高亮跳动（原案：EaseOutBack 弹入 + 1.8s 边缘光晕渐隐后上滑淡出）→ 2.5s 定格 → 全部折回胶囊收拢。复用 `QmIslandNotice` 与 PRESENTATION_HOLD_TIME 既有节奏，仪式有出处、有归宿，且强化灵动岛作为客户端签名元素的身份。

### P7 · 批四防回潮审计的补充检查项

`audit_motion_tokens.py`（未创建）除原定项（手写 smoothstep/指数衰减/硬编码时长、未响应动效等级的动画点、未接线 token）外，增加三类扫描：① 纯函数状态→图标/颜色直绘（无轨道的硬切换，P2 类缺陷的模式匹配）；② 调用点默认时长过度集中（节拍器回潮）；③ 常驻循环动效无静止窗口（呼吸必须可停）。
