# QmClient 交互与动效语言

状态：实验规范。用户已授权在独立分支自主选择实验路线。首轮聚焦设置分类、子页和共享导航反馈，视觉参数待实际客户端验收。

## 目标

操作及时得到回应，连续浏览不会被旧动画拖住。页面、滑块和弹层的运动帮助玩家理解当前状态，并沿用 QmClient 的布局、配置和组件体系。

本规范承接[UI 与 UX 现代化实施计划](2026-10-12-UI与UX现代化实施计划.md)中的已实现分类、导航和公共组件，不重排页面或改变保存格式。

## 首轮范围与状态

首轮沿设置分类、子页、卡片这条路径处理共享导航和卡片入场，包括快速切页、清单刷新、背景覆盖、动效等级及旧页输入释放。代码和配套测试已补充，尚未编译、运行测试或在真实客户端验收。

共享导航、卡片入场与表单输入的模块协作已进入本轮测试范围。整个客户端的弹层开关、滚动、加载反馈和其他页面节奏仍需后续逐条验收；首轮交付不代表完整 UI/UX 改造结束。

## 首轮行为规则

| 操作或阶段 | 预期行为 |
| --- | --- |
| 按下导航 | 选择、页面归属与对应反馈在当帧响应；滑块可以继续向新位置运动 |
| 快速连续切换 | 使用最新选择，正在运动的共享视觉元素接续当前状态；不排队播放过时页面 |
| 反向切换 | 可见位置保持连续，速度由现有动画后端接续 |
| 打开覆盖面板 | 下层导航保持当前动画画面，不因进入背景绘制直接跳到终点；输入归覆盖层 |
| 背景绘制 | 只读取已有动画值；不创建、重定向轨道，也不消费点击 |
| 测量或预热 | 不提交可见滑块，不通过测量推进动画或消费输入 |
| 关闭动效 | 选中状态和正文仍立即响应，显示目标几何；后续交互绘制结束相关旧轨道 |
| 减少动效 | 复用现有等级策略，保留可辨识的状态和层级反馈 |

导航按下切换已由用户明确确认。普通表单、确认和删除继续使用各自现有提交规则；立即视觉反馈与业务动作提交分别处理。

## 节奏与层次

- 同类导航共用 `UiTokens.h` 的导航弹簧，不为每个页面独立调一套参数。
- 页面入场、选中滑块、透明度和拖动具有不同目的，分别选择已有的位移、弹簧或缓动策略。
- 新动画不引入等待时间或整段输入锁。空间变化由实际显示几何参与裁剪和交互。
- 材质和装饰服从内容可读性。本轮保留现有配色、表面和布局，不加入新的玻璃或模糊效果。

## 首轮实现与证据

基线已包含 PR #431 的按下导航与卡片连续入场。本轮静态发现：`CapsuleTabBarChrome` 和 `NestedSegmentChrome` 在背景绘制时跳过动画求值，却直接采用目标矩形。因此导航运动中打开覆盖面板，会在这条绘制路径提交终点几何。

实验将两种共享导航的滑块属性统一为：交互阶段复用现有弹簧解析；背景阶段读取同一轨道的当前值；缺少动画值时使用目标几何且不初始化轨道。动效关闭时直接绘制目标。

配套集成测试使用真实 UI、共享导航和动画后端，设备边界由现有 fixture 替换。检查背景覆盖与恢复、首次背景出现、背景布局变化、关闭动效及嵌套滑块的各个几何通道。

卡片层还存在两条中断路径：同页卡片集合或模型索引刷新会在重建单卡缓存时清掉共享入场标记；首次背景绘制会消费尚未前台展示的入场周期。实验将共享入场生命周期保留在显示周期和实际切页处，背景只读取已有入场值，不消费首次入场。

新增 Deck 集成测试直接连接生产 `RenderCached`、卡片绘制、UI 和动画后端，使用生产 `ResolveCardMotionSpec`。以未中断的另一套 Deck 为参考，观察卡片最终内容坐标，覆盖连续正反切页、卡片增减、模型索引重建和背景恢复。另检查按下时正文切换、减少与关闭动效、旧输入框释放后保留文字，以及可见入场位置的控件点击。完整菜单文字池与配置接管是目标外依赖，测试桩误入即失败，不替代 Deck 或卡片绘制。

本轮累计已补充 15 项集成测试，未执行。已完成静态自查、差异空白检查、测试注册库存和 skill 结构校验。未编译、未运行 gate、未启动客户端；没有视觉、性能或运行时通过结论。

## 后续场景验收

获得对应运行验证授权后，在真实客户端观察设置分类与子页快速正向、反向切换；滑块移动中打开并关闭更新或新功能面板；在关闭、减少和完整动效等级下重复操作。必要时保留连续录屏，区分输入响应、画面跳变与帧时间问题。

真实客户端验收还需检查：入场中点击卡片控件、卡片清单动态增减、编辑中切页再返回，以及带滚动容器的页面。当前 Deck 集成测试隔离了滚动容器，没有实际窗口、GPU、帧时间或跨平台证据。

本轮不根据静态修复宣称整体丝滑。后续扩展到弹层、滚动或其他反馈时，继续沿具体玩家路径逐项确定范围和证据。
