# QmClient 交互与动效语言

状态：实验规范。用户已授权独立分支实验、编译与相关测试。本轮代码和自动回归已完成，真实客户端视觉与交互仍待验收。

## 目标与范围

操作及时得到回应，连续浏览不会被旧动画拖住。页面、滑块和弹层的运动帮助玩家理解当前状态，并沿用 QmClient 的布局、配置和组件体系。

本规范承接[UI 与 UX 现代化实施计划](2026-10-12-UI与UX现代化实施计划.md)。本轮沿页面切换、弹层开关、返回时的滚动状态与公共控件反馈完成实验，不重排页面或改变保存格式。

基线已包含 PR #431 的按下导航和卡片连续入场。本轮保留该行为，修复动画接续、绘制阶段及显示几何中的具体中断路径。

## 行为规则

| 操作或阶段 | 预期行为 |
| --- | --- |
| 按下导航 | 选择、页面归属与对应反馈当帧响应；滑块继续向新位置运动 |
| 连续或反向切换 | 使用最新选择，接续当前可见位置和速度；不排队播放过时页面 |
| 重复点击当前页 | 保留尚未完成的入场方向和进度，不重新起步 |
| 主页面入场中切换浏览器子页 | 外层页面继续归位，子页切换不清掉外层位移 |
| 打开覆盖面板 | 输入归覆盖层，下层导航、按钮、开关与原焦点外观沿用已有动画画面 |
| 背景绘制 | 读取已有轨道，不初始化、重定向或消费输入；隐藏滚动条也不消费待定位请求 |
| 测量或预热 | 不提交可见控件，不推进轨道或消费输入 |
| 弹层入场中关闭、退场中重开 | 显隐共用同一轨道，从当前位置、尺寸与透明度接续 |
| 逻辑关闭弹层 | 立即释放输入与回调，退场外框不阻挡下层；嵌套焦点沿用现有恢复机制 |
| 显示几何变化 | 可见矩形决定命中和裁剪，布局矩形维护稳定的滚动内容范围 |
| 关闭动效 | 立即显示目标；前台结算旧轨道和目标缓存，重新启用不重播旧动画 |
| 减少动效 | 复用已有等级策略，保留状态与层级反馈 |

导航按下切换已由用户确认。普通表单、确认和删除沿用现有业务提交规则。明确忽略全局动效等级的动画保留原约定。

## 共享实现

同类导航共用 `UiTokens.h` 与现有后端。位移、尺寸、透明度和拖动分别选择已有策略，不加入等待时间或整段输入锁。本轮保留配色、表面和布局。

- 胶囊导航与嵌套分段在后台读取当前几何。主菜单、浏览器和游戏菜单的页面进度也区分背景与测量；Tee7、触控菜单和旧投票子页的反向切换复用同一方向接续规则。
- 卡片定义缓存和模型索引刷新保留 Deck 的共享入场周期。首次背景绘制不消费入场，返回滚动页面时按动画后的卡片矩形裁剪，内容高度仍按布局计算。
- 公共弹层复用现有动画后端合并显隐目标。客户端使用已绑定的 runtime，独立 UI 使用同后端与 LocalTime 兜底；后台仅更新时间基线，恢复时不补播整段后台时长。没有 runtime 和客户端时钟时即时显隐。
- 按钮、开关及输入框的后台反馈只读取原轨道。Oklab 颜色根据后端保存的两端与当前混合量求值，返回前台换目标时也从当前可见色接续。
- 关闭动效时，即使业务目标未变，公共解析器仍结算活动与排队轨道并同步缓存；关闭动效的颜色直接保留配置目标值。

加载和连接反馈本轮只读核对，保留现有状态文字、下载进度及取消入口，没有修改连接行为。

`qmclient-ui-motion` 的维护源位于 `.agents/skills/qmclient-ui-motion/`，安装副本位于用户 Codex skills 目录；两者已同步。来源、平台取舍和按需查阅入口见 skill 的 `references/sources.md`。
