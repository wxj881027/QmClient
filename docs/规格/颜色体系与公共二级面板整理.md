# 颜色体系与公共二级面板整理

更新日期：2026-10-02。状态：设置归类、公共颜色接线与前景兜底已实现；未完成的全量状态语义迁移仍作为后续讨论建议。

## 当前设置与实际控制范围

图形设置的“视觉效果”卡片统一承载颜色；“界面动画”保留动效强度、列表入场、高度过渡、重排与展示动画开关，以及现存弹层模糊开关。本轮不再把二级菜单背景与输入焦点环混入动画项。

| 表面或状态 | 配置入口 | 当前作用 |
| --- | --- | --- |
| 界面表面 | qm_ui_color / qm_ui_opacity | 全局界面、导航与浏览器面板主题来源 |
| 设置卡片 | qm_ui_card_color / qm_ui_card_opacity | 设置卡片表面 |
| 按钮 | qm_ui_dropdown_color / qm_ui_dropdown_opacity | 普通按钮、下拉触发器与共享图标按钮，沿用存档键 |
| 输入框 | qm_ui_input_color / qm_ui_input_opacity | 文字、数值与共享输入控件 |
| 展开列表 | qm_ui_dropdown_list_color / qm_ui_dropdown_list_opacity | 下拉展开列表，透明度为零也不切换角色 |
| 二级菜单 | qm_ui_popup_color / qm_ui_popup_opacity | 居中二级面板 |
| 文本 | qm_ui_text_color_mode / qm_ui_text_custom_color | 自动、固定白色、固定黑色、自定义；手动模式不随背景改变，图标独立 |
| 边框 | qm_ui_card_border_color | 卡片、公共二级面板与下拉展开列表共用来源 |
| 选中状态 | qm_ui_selected_color | 主题选中色；部分旧控件仍使用默认 token |
| 强调色 | qm_ui_accent_color | 开关等强调状态 |
| 输入焦点环 | qm_ui_focus_color | 共享输入框和数值输入焦点反馈 |
| 图标 | qm_ui_icon_color 等既有配置 | 白色、黑色、自定义、彩虹及双色图标模式 |
| 计分板 | qm_scoreboard_color / qm_scoreboard_opacity | 独立 HUD 表面 |
| 警告、错误、正文 | 语义 tokens 与既有主题字段 | 普通主题前景已由表面解析；警告等业务语义色仍保留独立表达 |

按钮、输入框、展开列表、二级菜单分成四项独立颜色和不透明度设置。文本另有自动、固定白色、固定黑色和自定义模式；自定义颜色始终可编辑，只有自定义模式才应用，切换模式保留之前选择。配置直接转换为 RGB，不再经过 UnclampLighting 强制提亮，也不再压暗二级表面；选择器、Hex 与 100% 不透明表面保持同一颜色语义。控件自身不透明度不再叠乘浏览器界面不透明度。低透明度仍与父表面和底图混合。既有 qm_ui_dropdown_* 存档键保留，新增角色全部公开显示；qm_ui_popup_glass 已删除。强调动作按钮、选中高亮及导航胶囊仍保留各自语义色。

## 公共组件边界

SecondaryPanel.h 负责公共标题栏、正方形关闭按钮、行布局、嵌套下拉策略和弹窗属性。字体商店、玩家国旗、浏览器国旗与翻译面板共用这些入口；业务内容和选中后动作仍由各自模块负责。大型面板通过 ResolveSettingsSecondaryPanelRect 复用字体商店的视口占比和尺寸上限。

纯图标按钮的绘制和点击区域统一经过 QmUiSquareIconButtonRect。带文字、导航标签与开关无需强行变为正方形。文字缩略、边框、内容留白仍应在共享布局中处理。

全屏遮罩只叠色，避免绘制缓存的菜单背景覆盖设置页面。关闭弹层模糊时，弹层绘制整体进入模糊抑制作用域，防止半透明背景或分隔线绕过开关再次触发自动背板模糊。

## 已实现的前景能力与后续方案

当前已有独立表面、透明度、强调、选中、焦点与图标配置。公共主题已增加表面前景解析，并覆盖卡片、输入框、弹层、下拉及共享按钮，后续仍需逐步完成全部状态语义迁移。

1. **前景对比度（已实现）**：公共解析器按实际表面与 alpha 选择黑/白文字，作用域提供反色描边并恢复调用方状态；自定义图标色可辨识时保留，否则采用统一前景。绘制与文字使用同一最终表面值；下拉状态 alpha 变化后分别解析。透明表面使用 SURFACE_BACKDROP 参考背板 token，不采样实际 GPU 背景，复杂底图仍需实机验收。
2. **状态解析**：normal、hover、pressed、selected、disabled、focus 应由统一语义状态推导。不要在控件里继续散落灰色覆盖、alpha 乘法和固定高亮；不同表面的角色可以拥有自己的状态幅度。
3. **嵌套角色**：二级面板、列表、输入框需要稳定的层级关系。配置用于定义少量表面角色，tokens 定义间距、边框、层级与状态权重，组件只消费解析后的角色，不自行读取配置并重新组色。
4. **恢复与旧版兼容**：复用现有颜色加独立 alpha 的重置入口。旧版翻译专属配置仍保留兼容路径；未来是否迁移到公共角色需要明确策略，不能静默改变已有用户主题。
5. **行为约束**：对比度、alpha 边界、用户覆盖、切换主题、重开和父子弹层状态使用真实生产接口测试；截图验证覆盖浅色、深色、透明、长译文、窄视口和非默认缩放。

建议按“表面角色 → 状态颜色 → 组件”三层收敛，而不是为每个控件再增加一套配置。前景可读性已落地，灰度矩阵、透明度和图标覆盖有生产行为测试。其余状态语义统一、颜色预览一致性与全量旧控件迁移仍是 brainstorming 后续方向，不代表已实现。


## 手动验收路线

1. 图形设置 → 视觉效果：按钮、输入框、展开列表、二级菜单四项背景分别设置浅色 100%、深色 100%、低透明度，检查标题、正文、提示、关闭与下拉图标；切换后立即生效，重新打开仍保留设置。下拉按钮与展开列表可分别调色，界面中没有深色玻璃选项。
2. 玩家国旗先选择任一国旗，再选择 default，关闭重开确认恢复默认；浏览器国家筛选也检查 default、清空搜索与无结果恢复。
3. 对照字体商店、玩家/浏览器国旗和翻译面板：标题栏、关闭按钮比例一致，原设置页保持底层；点关闭、外部空白、ESC 后可再次打开。
4. 翻译面板打开语言下拉：子列表不遮换底层页面，不把点击和滚轮传到原设置页；取消不改变原语言，父子层分别可关闭和重开。窄窗口和非默认 UI 缩放各检查一次。
5. 在线轮盘选一项后松开，快速按数字键、重复释放，动作只执行一次；ESC/失焦取消不执行动作，关闭动画期间立即重新按住打开后可以提交新的选择。建议用改名或好友切换等可观察操作检查结果。

以上为用户验收清单，自动状态机测试与颜色策略测试不能替代完整鼠标或玩家操作。


## 2026-10-02 人工验收反馈修正

- 颜色选择器底部模式按钮前景曾按另一个默认背景解析，实际绘制却使用禁用/活动表面；现在先确定最终 Fill，再将同一个 Fill 交给绘制与公共前景作用域。
- 原表面光照下限将黑色抬为灰色、暗红抬为亮红，右上角纯红又被提亮成粉红；移除这层隐式映射。色盘显示角点和鼠标提交共用 ResolveUiColorPickerSelection，右上角是当前色相的饱和纯色，底边是黑色，左上角为白色。
- 浏览器面板按实际 BrowserPanelColor/BrowserPanelElevatedColor 建立父表面作用域；控件前景不再读取无关弹层配置。此阶段普通按钮、下拉和输入框共用控件角色；后续按下述四角色方案拆分。
- 需重新验收：红色相右上角/黑色底边、Hex 与实际控件颜色；HSVA/RGBA/HSLA 模式按钮文字；浏览器刷新/加入/添加好友的文字图标；四项背景独立换色、展开列表低透明度不被二级菜单覆盖。


## 第二轮人工验收反馈

鼠标隔离由公共输入读取屏蔽当前和上一帧按钮状态，卡片 Deck 在预布局前后过滤输入快照。弹层打开时取消底层拖动，避免将屏蔽误认作释放而提交排序；活动嵌套弹层仍可读取自身输入。退出弹层后下一次按下恢复操作。

共享图标按钮通过统一反馈策略和 ui_token::feedback 的强度绘制悬浮、按下叠色与边框，禁用时不反馈，绘制与命中仍保持正方形。

文本手动模式优先于自动表面前景及彩虹标题；图标继续使用独立图标设置和可辨识度兜底。自动模式以父表面合成为参考，无法采样 GPU 场景时仍不声称逐像素准确。

新增行为测试调用生产鼠标过滤、卡片输入过滤、文本策略和反馈策略。它们不能代替真实色盘拖动、外部点击、ESC、窄窗口和长译文的人工验收。
