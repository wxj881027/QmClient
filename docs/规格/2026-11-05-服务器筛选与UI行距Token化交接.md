# 服务器筛选重做与 UI 行距 Token 化交接

日期：2026-11-05｜分支：`dyl_dev`｜状态：已落地并推送，视觉验收待人工在游戏内确认

## 一、交接摘要

这一轮把服务器浏览器的筛选面板重做收尾，并把服务器信息页、右侧筛选面板的行距与度量收进设计 token；同时下线了最后一套旧搜索框实现。

当前 `dyl_dev` 领先 `origin/master` 三个提交，均已推送：

```
b6e382febf refactor(ui): 地图上传搜索框改用 InputField 并删除旧搜索框
871468aa11 refactor(ui): 服务器筛选面板度量走 token
cda5a95be5 refactor(ui): 服务器信息页行距统一走 token
38f6e45d38 fix(ui): 修复滚动测量同源与收藏星标进场回归 (#558)   ← 已由使用者 squash 合入 master
```

更早的功能主体（底部难度滑条、右侧面板分类、收藏/暴露 IP 动画）已通过 PR #556（`e41bc5d6eb`）squash 合入 master。本地只有 `dyl_dev` 一个分支，**不要新建其他分支**：这是使用者的明确要求，所有开发都在 `dyl_dev` 上做。

## 二、需求脉络（便于理解为什么长这样）

1. 底部快捷条原本只有「星级 / 人数」和「收藏地图」筛选，要求增加「地图难度」筛选，并解决与右侧面板筛选功能重叠的问题。最终取舍：底部是厚胶囊离散滑条（0-6 难度 + 0 玩家开关），右侧面板承载星级、模式分类与其它筛选。
2. 右侧面板迭代：DDmaX 单独成小节（标题 `DDmaX · 古典`）、分割线改为「两头细中间粗」并压暗、`Next` 不参与翻译、删除游戏模式/玩家国家两节、三个滚动条宽度位置统一、选中项每次显示都滚到可见、折叠用滑动过渡而不是跳变、收藏按钮改 toggle。
3. 收藏星标出场动画：从 0.25 倍缩放 + 中段鼓起长到 1.0，`0.35s`，按真实帧间隔推进；信息页「暴露 IP」行从 0.85 倍缩放 + 下移 4px 淡入，让位方向是向下（复制按钮与列表下移，不是把上方内容顶上去）。收藏开关改为 `str_format("%s%s", Localize("Favorite"), Localize("Server"))` 拼出的「收藏服务器」。
4. 合并 origin/master 后出现 6 个测试失败，回退到 master 版 `QmScroll` 并更新一条契约断言后恢复。

## 三、本轮三个提交改了什么

### 3.1 服务器信息页行距统一（`cda5a95be5`）

`src/game/client/components/menus_browser.cpp` 的 `RenderServerbrowserInfo`：

| 项 | 改动前 | 改动后 |
| --- | --- | --- |
| 行高 | 三行信息用 `clamp(..., 11, 15)` 算出的 15；收藏/暴露 IP 两行固定 18 | 所有行同一个值（15） |
| 步长 | 每行各自计算，间距 2 散落在多处 | `RowPitch = RowHeight + RowGap`，统一由 `TakeRow()` 取 |
| 块高 | `4*15 + 18*(1+anim) + 2*5 + 2*2` 手工相加 | `2*内边距 + 按钮高 + 可见行数 × (行高 + 行距)` |
| 空间不足 | 只缩三行信息 | 所有行一起缩 |

块高在无动画时 92→93、暴露 IP 展开时 110→110，整体高度基本不变；行距不再忽宽忽窄。

### 3.2 筛选面板度量 token 化（`871468aa11`）

`src/game/client/QmUi/ServerBrowserFilterForm.cpp`：字号 14、行高 18、行间距 3、组间距 6、分割线参数原本都是字面量；胶囊网格两处分别是 **24px（难度星标）** 与 **26px（模式类别）**，同一个面板里同一种控件出现两种高度。现在统一走 `ui_token::server_filter`，两处网格共用 `CHIP_HEIGHT 24 / CHIP_GAP 4`。

### 3.3 旧搜索框下线（`b6e382febf`）

`CUi::DoEditBox_Search`（`src/game/client/ui.cpp`）自绘放大镜后转调旧的 `DoClearableEditBox` 渲染路径，全仓只剩地图上传选择器一处调用。改为 `ui_widget::InputField`（`EInputFieldMode::SEARCH` + `m_Clearable` + `m_SearchHotkeyEnabled`），与本仓库其余 45 处搜索框同源；随后删除 `ui.h` 的声明与 `ui.cpp` 的实现（净 −47 行）。

### 3.4 合并 master 后的审查修复（`38f6e45d38`，已在 master）

- 内容测量回退到显示偏移：`AddRect` / `ScrollHere` 曾改用滚动状态偏移，但调用方布局用的是 `Begin()` 输出的显示偏移（`ui_listbox.cpp` 里 `m_ListBoxView.y += ScrollOffset.y`），两侧不同源会在缓动窗口内产生残余量，内容骤缩时可能把 `ContentOverflows()` 判成假并 `Reset()`，视口跳回顶部。
- 收藏星标改为「收藏切换处登记地址 → 列表渲染消费并以 0 起播 → 落位即删除」；上一版删掉「未收藏行也插条目」后，首次收藏因表里没有条目只能按 1.0 插入，不再播进场；未收藏分支还会留下永久墓碑。
- 恢复被放宽的源码合同断言（原断言引用的 `CardFill` 局部变量仍在）。
- 修 clang-format 头文件顺序、长 tooltip 基线。
- **有意不修**：好友分组折叠状态仍以 `CategoryIndex` 为键（改成语义键需要重做键空间，收益低）。

## 四、Token 体系

设计令牌集中在 `src/game/client/QmUi/UiTokens.h`，值为**未缩放**值，调用方按 `UiScale` 自行缩放。现有分组：`color`（含 `TEXT_PRIMARY/SECONDARY`、`ACCENT_*`、`FAVORITE`、`FRIEND`、`SURFACE_*`）、`spacing`（`XS 4 / SM 8 / MD 12 / LG 16 / XL 24`）、`radius`（`TIGHT 6 / SMALL_MENU 5 / BASE 8 / MENU 10 / CARD 14 / PILL 999`）、`font`、`motion`、`feedback`、`elevation`、`settings`、`secondary_panel`、`confirm_dialog`、`discrete_slider`、`hud::font`、`ime`。

本轮新增两组：

```cpp
namespace ui_token::server_info   // 服务器信息页
{
	ROW_HEIGHT 15 / ROW_GAP 2 / MIN_ROW_HEIGHT 11 / BLOCK_PADDING 5
	COPY_BUTTON_HEIGHT 15 / LABEL_COLUMN_WIDTH 80 / LABEL_FONT_INSET 4
	TOGGLE_WIDTH 30 / TOGGLE_LABEL_GAP 6
	EXPOSE_APPEAR_DURATION 0.15 / EXPOSE_SLIDE 4 / EXPOSE_SCALE_FROM 0.85
}
namespace ui_token::server_filter // 右侧筛选面板
{
	LINE_HEIGHT 18 / LINE_SPACING 3 / BODY_FONT_SIZE 14 / SECTION_GAP 6
	SECTION_TITLE_SCALE 1.15 / CHIP_MIN_WIDTH 6 / CHIP_HEIGHT 24 / CHIP_GAP 4
	DIVIDER_HEIGHT 2 / DIVIDER_THICKNESS 1 / DIVIDER_INSET_RATIO 0.1 / DIVIDER_INSET_MAX 16
}
```

约定：新增界面数值先进 token 再引用；调用点不再写裸 `15.0f` / `24.0f` 这类字面量。要整体调紧/调松，只改 token 一处。

## 六、旧 UI 组件调查结论（本轮只做了第 1 项）

追实现链后发现：大多数「旧 API」只是薄封装，渲染早已换成新组件，改名收益低风险高，因此没有批量改写。

| 旧 API | 真实实现 | 是否已是新组件 |
| --- | --- | --- |
| `DoButton_CheckBox`（19 处，多在 `QmUi/cards/*`） | `DoButton_CheckBox_Common_WithLabelElement` | **是**：`ui_widget::ResolveBooleanControlLayout` + `ui_widget::DrawToggle`，字号取 `ui_token::font::BODY` |
| `DoButton_Menu`（144 处） | `DoButton_MenuInternal` | **是**：`ui_widget::SButtonSurfaceOptions` / `DoIconButton` |
| `DoDropDown`（45 处） | `ui_popups.cpp` | **是**：基于 `QmDropdown` |
| `DoEditBox_Search` | `DoClearableEditBox` 旧渲染 | 否 → **本轮已迁移并删除** |
| `DoScrollbarV` | 仅定义，**0 调用** | 死代码，可删 |
| `DoButton_Icon` / `DoButton_Sprite` / `DoButton_ButtonKey` | 已无定义 | 无需处理 |
| WarList 的 Name/Clan 单选 | `DoButton_CheckBox_Common` + `"X"/"O"` 字形 | 字形选态偏旧，可换成 `DrawMarkedControl` 圆点 |

token 缺口：`QmDropdown.cpp` 仍有 33 处 float 字面量；卡片内行距多为就地计算。

## 七、已知风险与未完成

1. `QmScroll` 的 settle 动画在合并 master 时被整份替换成 master 版本，这是**有意取舍**：master 的滚动状态合同测试要求内容收缩与不可滚动重置立即生效，视觉平滑由 `CScrollRegion::m_DisplayOffset` 承担。若要恢复「仍在溢出、上限变小」的平滑夹取，应让内容高度由显式 `SetContentHeightForNextFrame` 驱动，而不是改偏移来源。
2. `ui_listbox.cpp` / `ui_scrollregion.cpp` 判断「重新出现」仍用 250ms 时间差，持续低帧率或长卡顿时仍可能误判，属残留设计脆弱。
3. 收藏星标待播队列上限 64，超出会整体清空（正常使用不会触发）。
4. 动画与行距的最终观感只能由使用者游戏内确认；本轮交付的是静态检查 + 单测证据，没有录屏。
5. 若本地正开着 `DDNet.exe`，链接会报 `LNK1104`；需使用者关闭客户端后重试，**不要结束用户进程**。
