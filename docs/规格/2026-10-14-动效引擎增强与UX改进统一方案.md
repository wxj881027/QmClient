# 动效引擎增强与 UX 改进统一方案

## 1. 背景与三源输入

本方案合并三份输入，形成动效域的单一执行蓝图：

1. **P0 颜色纪律模式**（2026-10-13 已落地）：审计脚本（报告/检查/基线三模式）+ gate 防回潮 + 按文件计数基线。该模式验证有效，本方案将其复刻到动效域。
2. **UX 调查与体验改进方案**（docs/规格/UX调查与体验改进方案-Gemini.md）：五维度特性建议。其中微动效维度（对称弹窗动效、物理按压）已随 2026-10-14 动画迁移完成，其余维度均未启动。
3. **外部引擎审查五建议**（2026-10-14）：参数化弹簧、C¹ 打断、双轨阻尼、FLIP+Stagger、休眠阈值与调试面板。

## 2. 外部五建议与现状对照（2026-10-14 核实）

| 建议 | 现状 | 结论 |
| --- | --- | --- |
| ① 解析解替代数值积分 | 引擎已用阻尼谐振子闭式解析积分（QmAnimationBackend.cpp 解析解注释处） | **已达成** |
| ② 跨曲线打断速度继承（C¹） | 打断统一语义 = 转弹簧接管并继承 `Track.m_Velocity`（StartTrackInterrupt） | **已达成**（含 tween→spring） |
| ③ 参数化弹簧（Response/DampingRatio 构造，设计师直觉参数） | `SUiSpringConfig` 直接暴露物理量（质量/刚度/阻尼） | **差距：待做** |
| ③' 双轨阻尼（空间允许过冲，ALPHA/COLOR 强制临界阻尼） | 未做——欠阻尼配置下 Alpha 过冲被 Clamp 截断会产生曝光停滞 | **差距：待做** |

| ⑤' 可视化调试面板 | 无 | **差距：待做**（低优先，开发态） |

## 3. 统一路线图（四批）

### 批一：引擎底座收口（本批启动）

1. **参数化弹簧构造器**：`SUiSpringConfig::FromResponse(float ResponseSec, float DampingRatio)`（k = (2π/response)²、c = 4π·dampingRatio/response），现有物理量构造保留为底层形式；token 族逐步迁移为 Response 表达（NAVIGATION_SPRING 等先给出等价 Response 注释，不强改数值防手感漂移）。
2. **感知属性双轨阻尼守卫**：引擎在 `RequestAnimation` 按 `EUiAnimProperty` 分派——`ALPHA`/`COLOR_*` 强制阻尼比 ≥1（欠阻尼配置被钳到临界），空间属性（POS/WIDTH/HEIGHT）允许欠阻尼；调用方显式声明者除外。
3. **差异化休眠阈值**：按属性类型取 rest 判定——空间 0.25px 且速度 <0.5px/s、ALPHA 0.002、COLOR 0.001；吸附终值并移出活跃池（现有 RestEpsilon 机制升级为按属性查表）。

验收：引擎单测（阈值吸附、ALPHA 无过冲、Response 换算正确性）；现有 5360+247 全绿。

### 批二：编排原语

FLIP 记录/回放助手（First/Last 矩形差值 → 引擎轨道衰减）+ 按索引 Stagger 延迟原语；首个应用场景 = 设置卡片重排与列表增删（替代整体瞬移）。入场 stagger 保持无状态求值模型不变。

### 批三：UX 特性（按价值排序）

1. 设置全局搜索（数百配置项的可达性，UX 方案维度五）
2. 服务器地图卡片悬停预览 + 个人通关状态（维度三）
3. 异步资源骨架屏流光（维度一，资产页已有涓流基建）
4. 灵动岛事件聚合与悬停微控制（维度四）
5. 跟随好友平滑引导（维度三）
6. 通关成就感微仪式 / 冰冻可视化 / 聊天现代化（维度二，游戏内）

### 批四：动效域防回潮（P0 模式复刻）

`audit_motion_tokens.py`：扫描手写 smoothstep/指数衰减/硬编码时长、未响应动效等级的动画点、未接线的 token；按文件计数基线 + gate 检查项。启动时机：批一~二落地后跑一次生成基线。

## 4. 原则沿用

- 尺寸变化转场一律「满幅布局 + 揭示裁剪」，禁止内容跟随临时矩形重排。
- 大 ground（网格卡片/模态）不位移，运动留给小元素；浮层禁用过冲曲线。
- 动效分级（0/1/2）经 `qm_animation::ApplyMotionLevel` 单点缩放，禁止调用点手写分支。
- 无状态流逝求值用于虚拟化交错列表；引擎轨道用于状态型控件。
