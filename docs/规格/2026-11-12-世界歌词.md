## 玩家行为

- 在“歌词”卡片开启“世界歌词”，配置为 `qm_world_lyrics`，默认关闭。
- 世界歌词只在本机显示，与灵动岛歌词的显示开关独立；沿用当前音乐来源和歌词语言设置。
- 每句新歌词在当前镜头所见场景上方生成，锚点记录为地图世界坐标。角色移动或镜头缩放不修改已生成歌词的锚点。
- 世界歌词按歌词来源的逐字起止时间和当前播放位置展开，词间停顿和长音跟随实际时间；一个词包含多个字符时，在该词的时间范围内逐字展开。按完整文本布局，逐字出现时不反复居中或改变换行位置。
- 缺少逐字时间、当前进度或词文本不能完整对应原文时，显示整句。译文没有独立的逐字时间，保留整句显示。
- 长句自动换行，不添加截断省略号。世界歌词位于地图前景之上；Tee 与地图始终保持原有绘制顺序，世界歌词开关不改变两者的遮挡关系。歌词与 Tee 重叠时，歌词位于 Tee 上方。
- 当前句在锚点附近轻微漂浮，带浅蓝辉光。换句时，旧句冻结已展开的文字，在原处上浮并于 1.2 秒内淡出。
- 只保留当前句与正在淡出的上一句，避免快节奏换句持续堆积文字。
- 暂停时保留当前歌词的展开进度和锚点；恢复播放后继续跟随播放位置。同一句内快进或回退时直接更新可见字符，跨句时按新句处理。
- 关闭开关或离开游戏时清除歌词；换图清除旧地图锚点。
- 相同歌词在不同时间点出现时按新句处理。只收到翻译或切换歌词语言时保留当前锚点。
- 世界歌词和灵动岛歌词均过滤作词、作曲、编曲等带标签的署名信息；保留包含相关词语的正常歌词，不将所有带冒号的句子判为署名。
- 灵动岛保留整句横向滚动，以当前句播放进度决定视口位置。暂停时停止滚动，拖动歌曲进度时同步移动，换句后从新句进度开始；原文和译文共用进度。
- 当前句有起止时间时直接计算进度；结束时间缺失时使用下一句开始时间，仍无可靠时间信息时停在句首。歌词正文不添加截断省略号。
- 本次不包含逐字高亮、字符抖动、文闪或节拍分析。

## 实现范围

视觉参考 [DangoMusic](https://github.com/Sorihiko/DangoMusic)。QmClient 使用现有二维世界投影和文字辉光接口实现漂浮歌词，不引入该项目的 Minecraft 渲染依赖。

歌词展示组件负责接入来源、播放状态和生命周期；独立状态机保存世界锚点及淡出状态；渲染器缓存文字容器，在可见字符数量、文字内容、字体图集或窗口尺寸变化时重建；镜头移动只改变投影。

歌词来源快照提供行起止时间及当前播放位置，用于识别重复歌词和定位灵动岛视口。世界歌词从同一来源的完整歌词中匹配当前句，按词时间计算可见字符；淡出句保存最后一次字符数量，不跨帧借用来源数据。逐字数据晚到或同一句数据修订时可以更新进度，不重新生成世界锚点。

字符数量按完整 UTF-8 码点统计，传给文字渲染器的隐藏区间则转换为字节位置，避免漏掉最后一个字符及中文遮罩错位。

现代网易云采集保留歌词模型 `yrcInfo.yrc` 中的原始 YRC，并优先携带同模型的 `yrcTrans`；没有 YRC 时保留现有 LRC 回退。字段已通过只读检查本机网易云程序包中的歌词模型核实，这段原来源采集沿用网易云已有请求。缺失逐字数据时的社区请求由独立备用模块处理。YRC 解析保留普通括号和零时长标点、空格，防止整行丢失或文字与时间错位。

时间语义和文本边界参考 [AMLL YRC 解析器](https://github.com/amll-dev/applemusic-like-lyrics/blob/main/packages/lyric/src/formats/yrc.ts)、[AMLL 括号回归测试](https://github.com/amll-dev/applemusic-like-lyrics/blob/main/packages/lyric/test/yrc.test.ts) 和 [Lyricify YRC 整理](https://github.com/WXRIW/Lyricify-Lyrics-Helper/blob/master/Lyricify.Lyrics.Helper/Helpers/Optimization/Yrc.cs)。三字段 YRC 的词起点使用歌曲绝对毫秒；不按数值猜测相对偏移。

两种显示与哼歌共用署名标签识别，唱歌和哼歌发送规则不变。

## 社区逐字备用源

2026-11-12 实际读取邓紫棋《唯一》（网易云 ID `2083785152`）：当前网易云模型和歌词接口均没有 YRC，只有逐行歌词；[AMLL 社区歌词库](https://github.com/amll-dev/amll-ttml-db) 中存在该 ID 的逐字文件。用户确认加入备用源，并将缓存按播放器分类；此次只接网易云、QQ 音乐、Spotify，不新增 Apple Music 播放采集。AMLL 没有酷狗、汽水专属索引，本次不按歌名猜测其他平台版本。

- “歌词”卡片提供 `AMLL community lyrics` 开关，配置 `qm_lyrics_community` 默认开启。关闭后恢复原来源，取消未完成网络请求，保留磁盘缓存。
- 原来源有可用逐字时间时优先使用原来源。缺少时先读 DDNet 保存目录下的 `qmclient/lyrics/<播放器>/<歌曲ID>.yrc`，有效缓存可直接复用；缓存缺失或损坏才请求社区。
- 播放器子目录分别为 `netease`、`qqmusic`、`spotify`。网易云使用原始数字歌曲 ID；QQ 支持采集器的数字 songid 和 MID；Spotify 保留现有歌词查询选中的 track ID，不使用客户端的本地歌曲哈希作社区索引。
- Spotify 沿用现有曲目搜索结果，尚不能保证播放器的所有现场版、翻唱版都被精确匹配。社区请求不发送登录凭据，也不新增另一套按歌名搜索。
- 从社区对应的 `ncm-lyrics`、`qq-lyrics`、`spotify-lyrics` 目录读取现成 YRC，复用当前词时间解析，不引入 XML 或额外运行库。按 README 注明来源；外来数据沿原提供方协议，投稿者自主编写部分为 CC0 1.0。
- 读取、解析和缓存写入在后台作业完成。响应最多 512 KiB，网络请求设超时；完整校验逐字文本和时间后才通过临时文件替换缓存。损坏内容、错误页和无逐字时间的响应不覆盖缓存。
- 网络失败保留原歌词并退避 60 秒；未收录（404）退避 10 分钟。重新播放会优先使用已有缓存。切歌、进程或 generation 变化会使旧结果失效；原来源逐字时间晚到后立即优先使用原来源。
- 社区 YRC 的 `(0,0,0)` 空格附着到相邻词；行结束时间至少覆盖最后一个有效词，避免文字退回整句或歌词提前消失。
- 社区歌词按播放器当前进度选择自己的行，不拿原来源的行起点套社区时间轴。暂停和 seek 沿用播放器进度，世界歌词、灵动岛、唱歌与哼歌使用同一份有效歌词；当前原句与社区句相同才沿用原译文。
