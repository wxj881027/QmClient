# 分支世界、快速练习与 Rank 1 人工验收清单

- 日期：2026-11-14
- 状态：待人工执行
- 适用客户端：本工作区 `cmake-build-release` 构建的 `DDNet.exe`
- 范围：分支世界与预测、快速练习交互与录制、Rank 1 影子与查看模式
- 不在范围：移动端、协议与物理改动、性能基准结论

## 一、当前状况

### 1. 分支世界

快速练习启用时，客户端把服务器世界深拷贝成 `CFastPractice::m_PracticeBaseWorld`，主世界继续由快照推进，两边实体互不影响。退出练习销毁分支世界；`m_PracticeStartWorld` 保留启用瞬间的快照，供“重开练习世界”恢复机关状态。

预测读回分两层：`m_PredictedWorld` / `m_PrevPredictedWorld` 是世界快照，`m_PredictedChar` 与 `m_aClients[].m_Predicted` 是角色核心。追赶循环从分支 tick 补到服务器预测 tick，视觉循环再外推快速输入帧；两条循环共用 `practice_predict_plan.h` 的 tick 计划与 `practice_predict_publish.h` 的发布动作。

自动化证据：`qm-practice-predict-tests` 通过 31 项测试。LLVM 插桩构建测得 `practice_predict_plan.h` 与 `practice_predict_publish.h` 的行、函数、分支覆盖率均为 100%。同一二进制在 AddressSanitizer 下通过 31 项测试，未发现堆、栈或全局越界。覆盖率只覆盖上述两个预测头文件，不代表客户端整体覆盖率。

仍需人工确认：镜头插值、快速输入外推、音效与死亡反馈、实体机关交互、暂停与旁观切换。

### 2. 快速练习交互

救援点、手动救援模式、重生点、世界重开与手动录制分别由 `practice_rescue.h`、`practice_input_lock.h`、`practice_recorder.h` 的纯逻辑支撑；命令通过控制台与 Bind 菜单暴露，均不设默认按键。

Bind 菜单支持径向轮盘与圆角面板两种布局（`qm_bindwheel_layout`，默认面板）。内置页按上下文生成，不写入配置：快速练习页、练习页、练习影子页。

自动化证据：`qm_fast_practice_branch_state_test.cpp`、`qm_practice_input_lock_test.cpp`、`qm_dummy_input_test.cpp` 等单元测试通过。本日新增 14 项分身输入行为测试，覆盖按住开火切换分身、自动上锤刷新与重发节拍、关闭上锤后的释放边沿。完整 `testrunner` 通过 7082 项测试。

仍需人工确认：菜单层级与点击外部关闭、录制分段观感、影子页播放、按键绑定后的实际操作手感。

### 3. Rank 1

`CRankGhost` 从 `watchable.jsonl` 索引按地图与名次取官方回放，下载到 `qmclient/rank1/demos`，解析后写成 `qmclient/rank1/ghosts` 下的本地影子，交给 `CGhost` 加载。查看模式复用同一份多轨影子与 `rank_view_timeline.h` 的时间线，支持成员面板、镜头模式与成绩差值 HUD。练习影子组通过同一套查看模式播放。

自动化证据：`rank_view_timeline_test.cpp` 与 `qm_rank_demo_cache_test.cpp` 共 11 项测试通过；完整 `testrunner` 通过 7082 项测试。历史进程验证记录见 `docs/规格/界面整理与在线回放实施计划.md`，该记录不能替代本清单的当前构建实机验收。

仍需人工确认：Rank 1 页签加载态、影子外观与方向指示、查看模式相机与成员切换、缓存删除反馈、离线缓存播放。

## 二、架构一页

| 层 | 入口 | 职责 |
| --- | --- | --- |
| 分支世界 | `src/game/client/components/tclient/fast_practice.cpp` | 启用、退出、重开、救援、重生点、录制、预测循环 |
| 预测计划 | `src/game/client/components/qmclient/practice_predict_plan.h` | 追赶与外推的 tick 范围、末帧发布动作 |
| 预测写回 | `src/game/client/components/qmclient/practice_predict_publish.h` | 世界快照、角色核心、200 tick 位置环 |
| 分支状态 | `practice_branch_state.h` / `practice_input_lock.h` | 重绑、瞬态失败宽限、发往真实服务器的输入锁 |
| 救援规则 | `practice_rescue.h` | `/r`、冻结与深冻、弹药恢复 |
| 录制 | `practice_recorder.h` + `qmclient/local_world.*` | 分段、影子组落盘、事件流 |
| Bind 菜单 | `qmclient/bind_workshop.*` / `bindwheel*` | 轮盘与面板布局、上下文内置页 |
| Rank 1 影子 | `qmclient/rank_ghost.*` / `rank_demo_manifest.h` | 索引、下载、转换、加载与缓存 |
| 查看模式 | `qmclient/online_replay_player.*` / `rank_view_timeline.*` | 时间线、成员、相机、成绩 HUD |

数据流：官方索引 → demo 缓存 → 影子组 → `CGhost` 或查看模式播放器 → 渲染与 HUD。练习录制走本地影子组，最终汇入同一个查看模式。

## 三、人工验收准备

1. 以窗口化模式启动工作区客户端：`gfx_fullscreen 0`。
2. 连接本地服务器或练习服务器，选择一张竞速图。
3. 需要双人时启动第二个客户端，或用分身连接。
4. 每次验收记录日期、构建 SHA、地图名、截图路径与结果。
5. 破坏性操作前备份 `settings.cfg`，结束后还原。

## 四、分支世界验收

### BW-01 进入与退出隔离

1. 记录主世界当前位置与其他玩家状态。
2. 执行 `fast_practice_enter`。
3. 在分支世界移动、跳跃、死亡数次。
4. 执行 `fast_practice_exit`。

期望：进入后主世界仍按服务器推进；其他玩家看不到分支世界的移动与死亡；退出后镜头回到主世界当前位置，没有瞬移或长时间插值。

### BW-02 机关与移动方块隔离

1. 在分支世界触发门、开关或移动方块。
2. 切换回主世界观察同一机关。
3. 执行 `practice_restart`。

期望：主世界机关状态不受分支世界影响；重开后分支世界机关恢复到启用练习瞬间的状态。

### BW-03 救援点自动与手动模式

1. 在可站立地面执行 `/r`。
2. 执行 `/rescuemode` 切换手动模式，再执行 `/r`。
3. 在深冻状态下执行 `/r`。

期望：自动模式传送到最近安全地面并清除速度、钩子与冻结；手动模式只保存不传送；传送后人物皮肤不残留冻结外观。

### BW-04 重生点独立于救援点

1. 执行 `practice_set_checkpoint`。
2. 移动到别处并执行 `/r`。
3. 执行 `practice_restore_checkpoint`。
4. 执行 `practice_restart` 后再恢复重生点。

期望：重生点只回滚 tee，不改变世界；重开世界后重生点仍然有效。

### BW-05 世界重开与录制分段

1. 开始录制并跑一段。
2. 执行 `practice_restart`。
3. 继续跑并结束录制。

期望：重开不清空已录内容；重开后录制进入新分段；保存的影子包含两段轨迹，没有跨段直线。

### BW-06 预测追赶

1. 使用网络延迟或丢包工具制造 100 毫秒以上抖动。
2. 持续左右移动与跳跃。

期望：镜头不前后抖动；角色不与服务器位置持续分离；松手后预测位置平滑收敛。

### BW-07 快速输入外推

1. 开启快速输入，按住移动键。
2. 分别打开与关闭“快速输入作用于其他玩家”。

期望：开启时本体预览连续外推；关闭时其他玩家停在真实末帧，不跟随外推。

### BW-08 分身晚接入

1. 先进入快速练习。
2. 再让分身连接完成。

期望：练习保持启用；分身被纳入参与者；接入瞬间不瞬移、不额外跳跃。

### BW-09 重进与重绑

1. 在练习中死亡并等待服务器重生。
2. 观察宽限窗口内的画面。
3. 超过宽限时间仍无法解析角色。

期望：宽限窗口内分支世界冻结但画面稳定；重绑后检查点跟随新角色；超时后练习干净退出，不残留输入锁。

### BW-10 暂停、旁观与恢复

1. 打开暂停菜单或进入旁观。
2. 恢复游戏。

期望：暂停期间分支世界不推进；恢复后不补播暂停期间的音效；旁观视角回到正确角色。

### BW-11 预测反馈只播放一次

1. 在练习中连续跳跃、挥锤、使用钩子。

期望：每次预测 tick 的跳跃与钩子音效只播放一次；死亡特效只出现一次；分身与本体不重复触发同一 tick 的反馈。

## 五、快速练习交互验收

### FP-01 Bind 菜单两种布局

1. 设置 `qm_bindwheel_layout 0`，打开 Bind 菜单。
2. 切换为 `qm_bindwheel_layout 1` 再打开。
3. 在面板布局中滚动页面与行。

期望：轮盘与面板都完整显示当前上下文页；面板滚动不越界；切换布局后菜单状态不残留。

### FP-02 上下文内置页

1. 未启用练习时打开菜单。
2. 启用练习后再次打开。
3. 当前地图存在练习影子组时查看影子页。

期望：快速练习页只在启用时出现；影子页只在存在影子组时出现；影子行按修改时间从新到旧排列，行名包含所有者与时长。

### FP-03 菜单层级与关闭

1. 打开 Bind 菜单的面板。
2. 打开其中一个二级动作菜单。
3. 点击二级菜单外部。
4. 再次点击面板外部，然后按 Esc，再点关闭按钮。

期望：第一次点击只关闭二级菜单；第二次点击关闭面板；Esc 与关闭按钮行为一致；面板不吞掉游戏输入。

### FP-04 录制三键与失败回退

1. 开始录制，跑约半秒后暂停，再继续，再结束。
2. 在线路不足一秒时直接结束保存。

期望：暂停后继续产生新分段，不出现假直线；线路不足时保存失败并转为暂停，已录轨迹保留，可继续跑再保存。

### FP-05 练习影子组播放

1. 保存一组练习影子。
2. 从 Bind 菜单影子页进入查看模式。

期望：播放效果与 Rank 1 查看模式一致；玩家名带 `[P]` 前缀；事件音效按 `events.qmevt` 播放。

### FP-06 命令绑定

1. 把 `fast_practice_toggle`、`practice_restart`、录制开始与结束绑定到不同按键。
2. 分别用按键与菜单触发。

期望：两种入口行为一致；没有默认按键冲突；解绑后入口立即失效。

### FP-07 按住开火切换分身

1. 按住开火键不放。
2. 连续切换分身两次。
3. 保持按住并移动。

期望：切换瞬间不会停火；不需要再按一次开火键；松开后只产生一次释放边沿。

### FP-08 自动上锤节拍

1. 开启 `cl_dummy_hammer`。
2. 观察分身挥锤频率。
3. 关闭 `cl_dummy_hammer`。
4. 分别测试 `cl_dummy_restore_weapon` 打开与关闭。

期望：分身按固定节拍挥锤，约每 25 tick 一次；关闭后不再多挥一锤；武器恢复行为与配置一致。

### FP-09 切分身重置输入

1. 分别设置 `cl_dummy_resetonswitch` 为 0、1、2。
2. 按住移动与钩子时切换分身。

期望：模式 0 不重置；模式 1 重置即将变为分身的槽位；模式 2 重置即将受控的槽位；重置后没有残留移动或钩子。

## 六、Rank 1 验收

### R1-01 页签与清单加载

1. 进入竞速图，打开计分板或菜单的 Rank 1 页签。
2. 首次加载时观察加载态。
3. 断网后重新进入页签。

期望：非竞速图不显示 Rank 1 页签；加载态可见；失败时显示可行动提示，恢复网络后可重试。

### R1-02 请求影子

1. 在 Rank 1 页请求当前地图名次 1 的影子。
2. 观察下载与转换进度。
3. 跑图出发。

期望：进度可见；影子在出发时出现；下载与转换不退出服务器；断开请求后不残留任务。

### R1-03 查看模式基础播放

1. 进入查看模式。
2. 播放、暂停、拖动进度。
3. 观察终点成绩与检查点差值。

期望：时间线可拖动；成绩与差值来自回放数据；没有差值时不显示伪造数字。

### R1-04 成员面板与相机

1. 打开成员面板，切换选中成员。
2. 多选成员并使用多人同框。
3. 调整 zoom，再切换自由视角并拖动。

期望：成员顺序与影子组一致，00 为主选手；镜头跟随选中成员；同框模式框住全部成员；zoom 在自动取景上叠加；自由视角平移不跳变。

### R1-05 方向指示开关

1. 打开与关闭 `qm_rank_ghost_show_direction`。

期望：开关立即影响查看模式成员头顶的方向指示，不影响影子本身。

### R1-06 缓存与删除

1. 重复请求同一场次影子。
2. 删除该条目的缓存。
3. 断网后播放已缓存条目。

期望：重复请求命中缓存；删除前先卸载激活影子，demo 与 ghost 同时移除；离线时已缓存条目仍可播放。

### R1-07 练习影子组与 Rank 1 一致性

1. 用 FP-05 保存的练习影子进入查看模式。
2. 对比 Rank 1 回放的播放、成员与相机操作。

期望：两套来源的查看模式操作一致；离开后跑图同步模式恢复。

### R1-08 切图与重置

1. 加载影子后切换地图。
2. 返回原地图重新加载。

期望：切图后旧影子卸载；返回后不出现上一张地图的残留影子或成员。

## 七、组件回归重点

### UI-01 二级菜单与面板关闭

1. 打开 Bind 菜单的二级动作菜单。
2. 点击外部、按 Esc、打开另一个二级菜单。

期望：外部点击先关闭二级菜单；Esc 取消当前层；切换到另一个二级菜单时旧菜单不残留。

### UI-02 确认类浮层按键

1. 打开删除缓存的确认浮层。
2. 按回车，再按 Esc。

期望：回车不触发确认；Esc 取消；确认按钮带危险色并包含对象名。

### UI-03 Toast 不阻断

1. 触发保存成功与下载失败。
2. 在 Toast 显示期间点击游戏。

期望：Toast 不抢焦点、不阻断操作；失败提示可行动；最多同时显示三条。

### UI-04 窗口失焦与按键释放

1. 按住开火或移动键时切换窗口。
2. 返回游戏并松开按键。

期望：失焦不会让按键卡在按下状态；返回后输入正常；聊天、控制台或菜单打开时按键释放不会意外清空绑定。
