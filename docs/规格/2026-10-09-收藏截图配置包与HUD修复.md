# 收藏、截图、配置包与 HUD 修复

状态：已完成实现与静态审阅，待运行验收。尚未编译、运行测试或启动客户端。

## 已确认范围

- 地图收藏以浏览器中与服务器收藏并列的独立分类为主入口，移除栖梦功能页的重复卡片。全局搜索继续使用现有完整收藏卡片。
- 每次入服重新查询记分板分数；刷新中、失败或查无数据时显示最近成功的记录。沿用已有 DDNet SQLite 缓存和 Axiom JSON 缓存。
- Kog 落水榜按真正的 DDRace Team 记录队员，Team 0 不计数、不显示。首次落水冻结计一次；救起后实际再次出钩，之后落水才能再次计数。持续冻结不重复累计，首次看到已经冻结的角色只建立基线。
- 用户选择截图是否带水印，每次仅保存一张。水印可包含自定义文本、时间戳和地图名，沿用四角位置设置。
- 配置采用 `.qmconfig` 导入/导出包，包含现有受管配置、Bind 和用户选择的自定义 cfg；保留运行文件格式和自定义目录树。
- HUD 贴边问题涉及全部元素和四条屏幕边，用户反馈未调整缩放。保留现有布局条目结构、旧坐标解释和屏幕边重合判定。

跨局统计数据库、保存数量限制及 HTML 图表导出，用户于 2026-10-09 明确暂缓，本轮不实现。

## 玩家操作与实现

地图收藏使用已有浏览器页签。旧卡片的 stable ID 保留，避免破坏搜索与已保存的卡片身份。

截图继续使用菜单右上角截图入口。录像设置卡片与截图详情共用水印控件；自动水印默认关闭。手动截图、自动计分板截图和自动统计板截图走相同处理器，拍摄请求时快照保存选项、时间和地图名。后台保存任务合成像素，只写一张 PNG。拍摄元数据嵌入 PNG，移动文件后仍可用于历史截图导出；旧图没有拍摄地图信息时省略地图名，不用当前连接地图代替。

配置管理沿用设置中的配置文件卡片，原文件打开入口保留。`.qmconfig` 使用带版本号、导出时间和客户端版本的 JSON，cfg 原始字节以 Base64 保存。导出先保存当前配置，再加入四个受管文件和勾选的自定义 cfg。导入先预览内容，明确选择“导入并重启”后进行完整恢复；先备份，再暂存与替换，失败尝试回滚。成功恢复后阻止退出阶段旧内存配置回写。未列入包的自定义文件不删除。

包最多 512 个文件，单文件不超过 1 MiB，总原始内容不超过 16 MiB，包不超过 24 MiB。文件路径限定保存目录内的相对路径；拒绝重复路径、路径穿越和链接，不跟随自定义目录链接。

查分请求按入服代际隔离，取消或迟到的旧结果不得覆盖新请求。Kog 计数独立为可调用的状态策略，处理角色暂时不可见、换队、玩家身份变化和 ClientId 重用。

HUD 将绘制后报告的实际内容边界用于拖动偏移、尺寸、下一帧恢复和贴边。窗口或内容外框尺寸变化时回退当帧边界；未继续报告的测量和退出时的运行状态及时清除。聊天等内容偏移较大的元素，合法可见位置可能要求变换锚点处于屏幕之外；这些中间位置使用原布局整数字段的负值区间保存可见边比例，避免旧的非负锚点约束把它误存成贴边。旧正值布局坐标与 0/1 贴边值保持原义。

负值位置由本版本识别；把这些新布局配置交给旧客户端时，旧解析会将负值夹到 0，相关元素恢复为贴边位置。
