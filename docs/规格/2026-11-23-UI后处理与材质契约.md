# UI 后处理与材质契约

关联 [#649](https://github.com/wxj881027/QmClient/issues/649) 和 [菜单文字 MSDF](2026-11-21-菜单文本与MSDF性能方案.html)。本阶段处理背景模糊、设置卡片和菜单正文。全屏 bloom、景深和色调映射留在 P3。

## 渲染顺序与资源

| 阶段 | 输入与输出 | 分辨率和格式 |
| --- | --- | --- |
| 冻结背景 | `CGameClient::OnRender` 在世界或菜单背景之后、HUD 与菜单文字之前调用 `CUi::BeginBackgroundFrame`。支持多采样背景层的路径使用其 resolve 结果，其余路径捕获当前交换链。加载界面和直接渲染菜单各有帧边界入口。 | 背景层存在时与屏幕同尺寸。背景降采样输出为每轴 `ceil(像素尺寸 / 4)`。 |
| Dual Kawase | `CGraphics_Threaded::GaussianBlurRenderTarget` 把背景降两级，再升两级。各 pass 的输入和输出为不同的存活附件，并验证每一级的尺寸。 | 两级每轴分别再减半，奇数尺寸向上取整，结果与降采样输出同尺寸。OpenGL3/Vulkan 使用 RGBA8，Metal 使用 BGRA8。 |
| 界面合成 | `CUi::RenderGaussianBlur` 返回本帧是否提交了带圆角遮罩的背景。材质层在调用者的裁剪区内叠加渐变、磨砂和边缘效果。 | 使用当前 UI 映射和物理像素尺寸，复用圆角 SDF。材质本身不分配纹理或 RT。 |
| 菜单正文 | #646 的字形容器直接采样同一张 MSDF 图集。亚克力档用距离场阈值计算光晕，以一个受限的偏移采样计算柔和阴影，再与描边和填充按透明度合成。 | 光晕和阴影限制在有 padding 的字形四边形内，额外采样仅用于亚克力档的 MSDF 字形。 |

背景和模糊结果按 `PerfFrame()` 归属，每帧最多准备一份。消费者只能绘制当前帧的结果。分辨率或模糊模式变更时重建附件，退出或后端失效时释放。已有离屏背景层时可以延迟到第一个可见消费者才计算模糊，交换链捕获必须在绘制前景前提交。每个离屏 pass 由 Begin/End 恢复图形状态。合成时临时收紧裁剪区，绘制后恢复调用者的 UI 裁剪状态，使用普通 alpha 混合。测量趟和空白裁剪区不提交合成命令。GL3、Vulkan、Metal 分别使用自己的圆角、模糊和文字 shader 入口。

目前的渐变、磨砂、光晕和阴影都是静态材质。噪点直接取自面板局部物理像素坐标，回放暂停和录制速度不会改变它。后续若加入依赖时间的材质，输入使用游戏 tick 和插值后的游戏时间，回放和录制读取同一时间值。本阶段不增加动画时钟。

## 画质与回退

`qm_ui_material_quality` 位于图形设置的界面主题卡片，默认关闭。设置卡片继续使用卡片颜色配置，外沿光晕使用界面强调色。

| 档位 | 卡片 | 正文 |
| --- | --- | --- |
| 关闭 | 普通圆角表面 | 保持当前文字渲染配置 |
| 毛玻璃 | 同帧的圆角模糊背板 + 渐变色层 | 保持当前文字渲染配置 |
| 亚克力 | 更强的背板混合 + 带磨砂的渐变 + 两个边缘 SDF 绘制（阴影和光晕） | 已启用菜单文字 MSDF 的正文增加光晕和柔和阴影 |

卡片材质要求启用背景模糊、选择 Dual Kawase、支持圆角 SDF，且当前帧有可用背景。任一条件失败时使用原来的卡片表面。正文按 #646 的条件整块回退到位图，包括缺字、替换字体、未完成图集上传和后端不支持。材质开关不会改动原背景模糊配置、控件交互或名称牌。

## 成本与测量

3840×2160 时，Dual Kawase 的源和结果为 960×540，两级中间纹理为 480×270 和 240×135。四张纹理的像素数据合计约 4.57 MiB，实际进程显存还包含交换链、驱动、临时读回及可能的多采样背景层。实验 MSDF 图集的 2048×2048 RGBA8 数据另占 16 MiB。卡片合成增加的工作量按可见区域和卡片数增长，没有每张卡片单独计算的模糊或全屏效果。

比较相同设置页、同一地图和后端的关闭 / 毛玻璃 / 亚克力档。图集上传、首轮编译和设置页初始化在计时前完成，截图在计时后抓取。帧时间报告 p50、p90、p99、p99.9 以及超过 6.25 ms 的比例。GPU 时间与进程显存分别采样，不能由 CPU 帧间隔或纹理理论字节数代替。

4K 每档采样一次，p99.9 对单帧尖峰敏感。GPU 计时范围因后端而异，比较以同一后端为准。材质本身没有新增 RT，进程显存会随驱动分配波动。

另用 PresentMon 2.6.0 在 1924×1061 的常规 Windows 构建上采集 ETW。它记录到 OpenGL3 亚克力档的 GPU Busy p50 为 0.940 ms（2982 帧），Vulkan 毛玻璃档为 0.843 ms（1420 帧）。部分档位在稳态区间缺少 ETW 样本，4K 表采用客户端 GPU 查询。

Metal 的实机画面和性能、正式客户端在 4K 显示器上的前台长时间 A/B 仍待验证。
