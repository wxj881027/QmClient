### P0/P1 的执行方法

1. 每个缺陷记录最小操作序列、预期与实际结果、源码 SHA、配置、系统、渲染后端、窗口尺寸和缩放；先区分新配置与历史配置。
2. 能通过稳定生产接口复现的缺陷，先补会失败的行为回归，再修改共享实现。涉及系统 IME、字体或 GPU 的问题保留真实设备验证，不用源码字符串测试代替。
3. 修复同时覆盖重复调用、取消／重开、离页、用户覆盖与恢复路径；并发／异步场景给出明确超时，不能用任意等待掩盖竞态。
4. 运行相关单元／集成测试并构建受影响目标；跨进程或真实启动链变化补对应进程场景。按验证 skill 执行 gate，复用未变化范围的成功证据。
5. 只在完成标准和实际验收均满足后勾选；“已有实现”“自动测试通过”“实机验收通过”分开记录。

  **完成标准：** 未安装时启动 QmClient 不弹错误窗口；自定义盘符、含空格路径及已经运行的 Steam 可识别。自动启动关闭时不启动 Steam；自动探测失败后，手动指定有效路径仍能使用。调试记录能说明命中了哪种来源或为什么没找到。

- [ ] **D2. 接入服务器列表镜像。** **补充方案。**

  在现有 Qm 服务提供与官方相同格式的 `servers.json` 镜像，每 60 秒同步一次并记录最近成功时间；超过 5 分钟未成功同步时，标记为过期，不作为新鲜列表来源。客户端把镜像加入现有 HTTP master 候选与可用性选择流程，复用原解析器。失败刷新保留上次成功结果，并显示列表是否过期；不使用空响应覆盖正常缓存。

  **完成标准：** 官方源不可达时仍能从镜像获得列表；镜像失败或数据过期时可使用其他有效源。全部失败时保留旧列表并提示刷新失败。切换来源不重复服务器条目，也不丢收藏、筛选和当前选择。

- [ ] **D3. 实现免配置翻译的多服务回退。** **补充方案。**

  保留现有 MyMemory 适配器，在 Qm 翻译服务端接入 DeepL，并提供统一的自动服务入口；客户端仅提交文本、来源语言和目标语言。服务端保存维护者配置的 API 凭据，按服务及凭据分别管理额度、并发和冷却时间；客户端不内置公共密钥。首版顺序为可用的 DeepL → MyMemory，之后通过服务端配置调整。
  超时、临时服务错误、限流或额度耗尽时尝试下一个可用服务；同一请求对同一服务最多尝试一次，首版最多两次服务请求，单次最长 5 秒、全链路最长 10 秒。明确的内容拒绝返回 A5 的提示，不继续轮询服务。取消后不再启动后备请求。服务限额读取实际配置或接口结果，不把原始待办中的估算数字写死。

  **完成标准：** 新用户选择自动服务后无需注册服务账号或填写密钥；用户主动启用翻译后即可请求。已有的手动服务选择与个人密钥保持有效。主服务故障能切换；全部不可用时给出简短原因，不把错误正文发进聊天；过期结果不覆盖新请求。服务端可用后再将自动服务设为新安装的默认后端。

## E. 可选交互功能

- [ ] **E1. 延长连发表情弹射的可见时间。** **补充方案。**

  默认存活时间从当前的 3 秒调整为 5 秒，最后 0.5 秒淡出；在现有表情卡提供 1～10 秒的显示时长配置。每个弹射实例独立计时，同一玩家继续发送不会重置或清空上一枚；达到现有实例数量上限后才回收最旧实例。

  **完成标准：** 两端都使用支持此规则的 QmClient、且接收方启用他人弹射显示时，连续发送的表情都按接收方配置显示完整时长。忽略名单、关闭他人表情和现有发送限制继续生效；不通过提高发送频率延长显示。

- [ ] **E2. 在输入显示组件增加按键计数。** **补充方案。**

  增加默认关闭的“显示按键次数”，统计输入显示布局中启用的键盘键和鼠标键。一次按下计一次，长按和系统重复事件不累计；只在游戏取得操作焦点时计数，聊天、菜单和控制台输入不计入。统计范围为本次客户端会话，提供手动清零；关闭功能时暂停计数，重新开启保留本次会话累计值。位置与缩放沿用输入显示和 HUD 编辑器。

  **完成标准：** 按下十次显示十次，长按只增加一次，松开重按继续增加；切换主号／分身不会重复计数。清零即时生效，退出客户端后重新开始；关闭显示不影响游戏输入。

- [ ] **E3. 增加草、番茄、鸡蛋三种装饰投掷物。** **补充方案。**

  在表情菜单增加投掷物页签，选中后向当前瞄准方向抛出，允许绑定快捷键。复用已有弹射运动与视觉碰撞，新增三套透明素材；命中后播放短粒子效果并消失，没有伤害、冻结或推动角色的效果。功能默认关闭，显示开关放在表情卡。
  同步通过现有 Qm 实时通道新增独立的可选事件，携带投掷物类型、起点和方向，沿用同服身份校验与发送限制。接收端校验类型、坐标与方向；旧客户端忽略未知事件。此功能不要求修改 DDNet 游戏协议。

  **完成标准：** 支持该功能的同服 QmClient 能看到同一种投掷物；不支持的客户端不报错。关闭他人效果或屏蔽发送者时不显示；命中动画不改变角色状态，切图和断线后清理残留实例。
