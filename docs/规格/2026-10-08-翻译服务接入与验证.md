# 翻译服务接入与验证

状态：2026-10-08 代码实现与本地自动验证完成；真实 API、本地模型和视觉验收待完成。本文维护本轮决策和验收证据。

## 服务范围

新增百度通用翻译，用户配置 APP ID 和 API 密钥。保留智谱、DeepSeek、OpenAI、自定义 OpenAI 兼容服务、DeepL、MyMemory、腾讯云和 LibreTranslate、FTAPI 的已有入口。微软翻译不接入。

智谱客户端默认模型继续使用 `glm-4.7-flash`。个人凭据由设置页填写，不在客户端内置公共密钥。公共翻译计划使用现有服务器上的网关，智谱为主、百度为备用；本轮没有实现或部署网关，也没有启用跨服务自动回退。MyMemory 保留手动选择，不作为计划中的默认公共回退。

百度请求使用 HTTPS POST 表单，签名基于原始 UTF-8 文本；密钥只参与 MD5 签名，不进入请求体。转换客户端语言码，多段译文全部有效后才发布。服务错误码映射到稳定分类。

## 本地 LLM 与模型兼容

自定义服务新增两种明确认证模式：Bearer API key；本机无认证。本机无认证仅接受 localhost、127.0.0.1、IPv6 回环地址；不发送 Authorization 头。云端 Provider 继续按原认证要求处理。

自定义服务默认省略采样、token 上限和思考参数，遵从模型服务的默认行为。用户可以明确选择 thinking、enable_thinking、chat_template_kwargs 三种 Chat 参数格式，并选择发送采样和 token 上限。服务默认值不代表模型已关闭思考；Chat 专用思考参数不能隐式转入 Responses 请求。OpenAI 使用 max_completion_tokens，避免向推理模型强制发送 temperature 或旧 max_tokens。

本机连接超时为两秒，任务总超时为三十秒；普通云端 LLM 保留有限时限。任务队列继续共用容量限制，不增加无界等待队列。本地失败不自动转交云服务。

## 结果与诊断

共享 HTTP 后端负责状态分类、请求取消、响应大小上限和完整译文校验。空文本、无效 UTF-8、内嵌 NUL、超过结果容量、HTTP 失败、token 截断和 Responses 未完成状态不能成为成功译文。

MyMemory 超过 500 字节时明确提示输入超限，不截掉尾部；FTAPI 查询 URL 超过引擎容量时在提交前失败。LibreTranslate 允许成功响应缺少 detectedLanguage。DeepL 归一简繁中文及英语、葡语的来源地区码，额度提示不再假定按月重置。

聊天失败仅显示本地化短提示，不展示供应商原始响应。诊断只保留服务名称、HTTP 状态和稳定失败分类，不保存密钥、完整聊天或原始错误体；翻译请求关闭引擎 URL 失败日志，避免带文本的查询 URL 进入日志。自动出站失败恢复原文、显式出站失败不发送，沿用已有策略；服务错误及部分译文均不发送。

设置页提供测试翻译，使用生产后端翻译固定短句并展示实际结果。一次只允许一个测试请求，支持取消；离页、配置变化和重新测试使旧 owner 失效。最近聊天错误可以在同一诊断区域展开查看。原页与搜索页共用控件、内容测量和动态高度缓存失效。

## 配置入口

在翻译设置选择“百度翻译”，填写应用 ID 和 API 密钥，然后点击“测试翻译”。对应控制台配置为 `qm_translate_backend baidu`、`qm_translate_baidu_app_id`、`qm_translate_baidu_key`。个人智谱和 DeepL 继续在各自服务设置中填写凭据。

本地模型选择 LLM 的自定义 Provider，填写已启动的 OpenAI 兼容服务端点和实际模型名称；无认证服务选择“本机服务，无需认证”。思考参数默认使用服务默认值，只有确认服务支持相应格式后才选择明确的参数格式。测试不会下载模型或启动模型进程。
