# 快速练习与绑定菜单

## 目标

快速练习是客户端侧的**分支世界**：从进入那一刻的服务器世界 fork 出一条独立世界线，
主世界照常推进，两边互不影响；退出即销毁分支。练习里提供与服务端 `/r` 一致的救援、
世界重开、重生点与手动录制，并把所有可绑定动作收进一个通用 Bind 菜单。

不做游戏 tick 变速，不做自动录制，不改服务器协议与物理。

## 世界模型

- `CGameWorld m_GameWorld` 是主服务器世界，快速练习期间仍然独立推进。
- `CFastPractice::m_PracticeBaseWorld` 是 fork 出的分支世界，预测与渲染都以它为准。
- `m_PracticeStartWorld` 是启用瞬间的深拷贝快照，只给"重开练习世界"用；主世界已经走远，
  无法再从 `m_GameWorld` 取回那一刻的机关、移动方块和开关状态。
- 退出练习 = `m_PracticeBaseWorld.Clear()` 销毁分支；已落盘的 `.gho` 是普通文件，不受影响。

## 救援点与 `/r`

`/r` 只回滚 tee，不回溯世界，行为对齐服务端 `ConRescue`：

- 自动模式：每个 tick 只要满足"不在冻结中、不在深冻中、站在地面上、不在冻结道具拾取范围内"，
  就把当前位置和完整 tee 状态记成救援点（覆盖式更新，不做历史队列）。
- 手动模式（`/rescuemode`）：`/r` 只保存当前救援点，不传送。
- 传送被 `/super`、`/invincible` 挡住时只保存不传送，与服务端一致。
- 传送后解冻（含深冻），并清空速度、钩子与已触发事件；武器弹药按服务端 `CSaveTee`
  规则恢复（读档后弹药为 -1，即"不再装填"）。
- `m_FreezeEnd` 是服务端按剩余冻结量现算的网络字段，`CSaveTee` 不保存它，恢复救援快照时
  必须按同一口径重算（深冻 = -1，未冻结 = 0）。漏算会留下 `/deep` 的 -1，出现"人能移动、
  渲染却一直是冻结皮肤"的假象。

规则判定集中在 `src/game/client/components/qmclient/practice_rescue.h` 的纯函数里，
逐条对应服务端的 `CCharacter::TrySetRescue` / `Rescue` / `Unfreeze`。

## 世界重开

`practice_restart` 用 `m_PracticeStartWorld` 重建分支：检查参与者集合是否仍有效，
保留当前开火输入，重新清洗钩子、同步配置、重置时间线状态，并切一个录制段。
录像历史保留，重开只切段，不丢已录内容。

## 重生点

与救援点相互独立：`practice_set_checkpoint` 显式保存当前 tee 状态，
`practice_restore_checkpoint` 只回滚 tee 并解冻，世界继续运行。重生点在重开世界后依然有效。

## 录制

全手动，三键：开始/继续、暂停、结束并保存。

- 开始：`BeginTrack` 以当前分支时钟为起点，本体轨 0、分身轨 1。
- 暂停：停止采样但保留已录内容。暂停期间 tee 照常跑，若继续采样会把空洞连成一条
  假直线，所以继续录制时 `MarkSegmentBoundary` 切段。
- 结束：先 `SavePracticeGhost` 落盘再 `EndTrack`（顺序反了轨迹缓冲已被清空）。
  保存失败（线路不足约 1 秒、录音器忙）时不清空轨迹，改为暂停，用户可以接着跑再结束。
- 保存使用 `CLocalWorld::BestSegment`：当前段够长取当前段，否则取刚封存的那段。
  反复重试不会堆积垃圾，但更早的段不会保留。

落盘格式与 Rank 1 组回放相同：`ghosts/<map>_<name>_<time>_<stamp>_<sha>/trackN.gho` 加
`events.qmevt`，玩家名带 `[P]` 前缀。它不参与个人最佳比较，也不影响 rank。

## 绑定菜单

`CBindWheel` 从"仅轮盘"扩展为通用 Bind 菜单：`qm_bindwheel_layout` 选择径向轮盘（0）
或圆角面板（1，默认）。面板布局支持滚动，鼠标滚轮在页签上切页、在行上滚动。

打开菜单时按上下文生成内置页，不写入配置：

| 页 | 何时出现 | 内容 |
| --- | --- | --- |
| 快速练习 | 快速练习启用中 | 进出练习、重开世界、重生点、录制三键、保存线路、常用 `/` 指令 |
| 练习 | 普通练习队伍 | 服务端 practice 无参指令 |
| 练习影子 | 当前地图存在练习影子组 | 每个组一行，直接进 demo 式查看模式播放 |

影子页按目录修改时间从新到旧排序，行名是"所有者 + 时长"。

## 命令

| 命令 | 说明 |
| --- | --- |
| `fast_practice_enter` / `fast_practice_exit` / `fast_practice_toggle` | 进入 / 退出 / 切换 |
| `practice_restart` | 回到启用瞬间的世界快照 |
| `practice_set_checkpoint` / `practice_restore_checkpoint` | 设置 / 回到重生点 |
| `practice_record_start` / `practice_record_pause` / `practice_record_stop` | 录制三键 |
| `practice_save_ghost [name]` | 兼容旧入口，直接保存当前可用段 |
| `practice_view_ghost <dir>` | 播放指定练习影子组 |

以上命令都不设默认按键，只作为控制页可绑定项与菜单项。

## 验证与边界

- 规则与快照映射有单元测试：`src/test/unit/qmclient/client/qm_fast_practice_rescue_test.cpp`、
  `qm_bindwheel_state_test.cpp`。
- 录制、菜单与影子页依赖真实客户端状态（分支世界、磁盘影子组），当前只能实机联调验证。
- 径向轮盘在条目很多时（例如影子页）会显得拥挤，面板布局不受影响；默认已是面板布局。
