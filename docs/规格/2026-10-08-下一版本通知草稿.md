# 下一版本通知草稿

状态：2026-10-08 开发草稿，未发布、未推送到 Markdown 广播。正式版本号未调整；以下内容须在对应验收完成后再用于发布。

## 主要变化

- 调整 IME 焦点交接和候选文字更新；地图编辑器输入框重新由编辑器管理。
- 中文发往日语时不再仅凭汉字跳过翻译；服务拒绝和错误使用本地化短提示。
- 聊天翻译按钮放到输入行最左侧、聊天类型前缀之前；长名称或多标签下正文缩进保留合理宽度；HUD 手动布局可以按可见内容重新贴边。
- DDNet、TClient 和 Qm 设置接入共用卡片，搜索结果直接展示相同控件；统一卡头动作区和卡片底部说明。
- 新增按键次数、提示气泡外观和手动应用的栖梦推荐外观。按键计数默认关闭。
- 表情弹射默认显示 5 秒，可设置为 1～10 秒；饼菜单增加圆角、选中色调及开合效果开关。
- TClient 配置统一为 `qm_` 前缀，继续兼容旧名称和绑定；已有用户的省略默认值保留。
- Steam 卡片显示探测状态，支持重新检测和手动客户端路径。
- 服务器列表加入 Qm 镜像候选，刷新失败保留旧列表，并显示失败或过期提示。
- 新增可选“自动（Qm 服务）”翻译后端，由服务端按 DeepL → MyMemory 回退，客户端无需填写维护者密钥；现有手动后端保持可用。
- 新增草、番茄、鸡蛋装饰投掷物，默认关闭；可在表情菜单选择或绑定快捷键，命中只播放视觉效果。
- 新版通知记录已读版本和内容修订，只在空闲主菜单提醒。

## 已知问题与临时处理

- 微软拼音在聊天输入框连续输入拼音时吞字仍待定因；不能把候选文字、焦点或空文本保护改动视为问题已经根除。遇到问题时保留具体输入步骤及输入法版本。
- 当前卡片迁移尚未完成编译与实际交互验收，完整控件、条件内容和切页后的焦点行为仍待检查。
- 窄窗口、高 DPI、200% UI 缩放和不同输入法仍待实际验收。遇到遮挡可暂时调小 UI 缩放并记录页面与窗口尺寸。
- LXGW WenKai 不可用时，推荐外观保留当前字体和字重；可在字体入口安装可用字体后重新应用。
- 镜像、自动翻译和投掷同步的服务代码已接入但未部署；自动翻译须在服务与维护者凭据可用后使用，投掷物的远端同步须双方客户端和中心服务均支持。本地装饰效果及现有个人翻译后端保留。
