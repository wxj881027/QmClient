# QmClient UX 调查与体验改进方案

## 1. 背景与目标

QmClient 基于 DDNet / TaterClient 架构，持续推进界面视觉与交互体验的现代化。当前客户端已建立起相对完善的 `QmUi` 基础体系，包括半透明卡片流式布局、Spring 弹簧物理动画系统、Media Island（灵动岛）多媒体交互、平滑圆角以及分级动效控制（`qm_ui_motion_level`）。

在国旗图标加载入场动效、Tee 形象展示入场动效落地后，客户端微动效与触感交互的基础范式已经成型。为了进一步提升玩家在浏览菜单、跑图竞技、找服社交和个性化配置全链路中的操作舒适感与质感，本方案对客户端现有的体验断点进行了系统性调查，并整理出可落地的 UX 演进规划。

---

## 2. 交互体验五大维度调查与改进建议

### 维度一：微动效与质感体系（Micro-Interactions & Fluidity）

#### 1. 弹窗与对话框的“对称式开闭动效”
- **当前现状**：选择国旗、地图筛选、设置二级弹窗和确认对话框在打开时已有或正引入弹性入场，但关闭时大多为硬切消失，缺乏自然退场的视觉延续性。
- **改进方案**：
  - **展开（In）**：以点击触发源（按钮或光标）为几何锚点，采用参数化 EaseOutBack 曲线（Scale 0.90 $\rightarrow$ 1.05 $\rightarrow$ 1.00，伴随 Alpha 0 $\rightarrow$ 1，耗时约 240ms）。
  - **关闭（Out）**：快速缩放淡出（Scale 1.00 $\rightarrow$ 0.94，Alpha 1 $\rightarrow$ 0，耗时 120ms~150ms 迅速收回），避免阻碍玩家后续操作。
  - **背景遮罩（Backdrop）**：弹窗激活时底层背景平滑过渡至半透明暗化并叠加轻微模糊，按 ESC 或点击外部时同步淡出。

#### 2. 卡片与按钮的“物理悬停/按压触感”
- **当前现状**：多数按钮与交互卡片仅通过单纯的色彩亮度（Alpha / Brightness）体现鼠标悬停，在半透明玻璃拟态卡片下显得较为扁平。
- **改进方案**：
  - **悬停浮起（Hover Elevation）**：鼠标悬停到重要按钮或设置卡片时，Y 轴上浮 1~2px，边框光晕微亮，给予玩家“可交互”的明确心理反馈。
  - **按压下凹（Active Press）**：鼠标按下瞬间微缩放至 0.98x，松开时弹性复原，提供轻快的机械按键感。

#### 3. 异步资源的“骨架屏流光”（Skeleton Wave Shimmer）
- **当前现状**：地图预览图、皮肤纹理在弱网或大量解压尚未就绪时，偶尔呈现纯黑或灰色占位块，加载完成后突兀切出。
- **改进方案**：
  - 占位矩形内部叠加从左向右循环扫过的浅色渐变光带（Wave Shimmer）。
  - 告知玩家系统处于正常的异步拉取中，消除“无响应”或“资源损坏”的疑虑。

### 维度二：局内核心交互与跑图反馈（In-Game Spatial UX）

#### 1. 刷新纪录与通关的“成就感微仪式”
- **当前现状**：DDNet 通关或打破个人最佳时间（PB）时，信息主要输出在聊天栏或屏幕顶部简单文字，对于经过长时间挑战攻关的玩家，缺乏正向情绪回馈。
- **改进方案**：
  - 触发刷新记录（PB）或初次通关时，在屏幕正上方触发轻量级庆祝动效：
    - 勋章图标以 EaseOutBack 弹性弹入；
    - 提升时间高亮跳动显示（例如 `-03:24.12`）；
    - 屏幕边缘微弱柔和光晕渐隐，持续 1.8 秒后上滑淡出，不遮挡后续操作视线。

#### 2. 冰冻（Freeze）与救援状态的空间可视化
- **当前现状**：在多人混战或高难度接力图中，队友或自己被深冻、或解冻倒计时即将结束时，容易淹没在密集角色与特效中。
- **改进方案**：
  - **临界脉冲**：解冻条剩余最后 1 秒时，进度条颜色转为高频呼吸泛光，提示附近队友争分夺秒完成锤击救援。
  - **视口边缘救援指示**：当绑定搭档或好友在屏幕外被深冻时，屏幕边缘显示带队友小头像/国旗的半透明微型箭头，指示空间方位。

#### 3. 局内聊天（Chat）现代化交互
- **当前现状**：聊天窗口字号与输入框较小，翻查历史记录和输入表情操作流程较为繁琐。
- **改进方案**：
  - **快捷表情弹窗**：输入 `:` 时触发紧凑的悬浮表情面板，支持模糊键入与回车确认。
  - **@提及高亮**：当局内消息包含玩家自身昵称时，整行消息背景显示呼吸高亮底色，降低高强度跑图中漏读关键呼叫的概率。

### 三、 服务器浏览器与选图体验（Browser & Discovery）

#### 1. 地图卡片式悬停预览（Map Card Hover Preview）
- **当前现状**：服务器列表中仅显示地图名称、星级和人数，玩家在选图时无法直观了解地图地形风格与起点构造。
- **改进方案**：
  - 光标停留在地图名称上 0.3 秒后，展开轻量浮动卡片：
    - 展示按需下载的地图缩略图（带居中弹性入场）；
    - 标注地图分类标签（Novice / Moderate / Brutal / Solo 等）；
    - 显示个人通关状态：未通过 / 个人最佳成绩 / 距离世界纪录差距；
    - 展示地图作者与发布日期。

#### 2. “跟随好友”（Join Friend）平滑引导与自动排队
- **当前现状**：好友常玩服务器经常处于满员状态（如 64/64），玩家盲目点击只会收到连接失败提示。
- **改进方案**：
  - 在好友名片增加“满员自动排队”选项，一旦检测到有玩家断开并腾出空位，立即发起连接并弹出提醒气泡。

---

### 四、 灵动岛（Media Island）全局环境中心（Ambient Hub）

#### 1. 全局事件通知聚合
- **当前现状**：Media Island 核心服务于音乐播放器与歌词同步，在未播放音乐时大多处于隐匿状态。
- **改进方案**：将灵动岛升级为无干扰的“胶囊状态中心”：
  - **好友动态**：好友进入游戏时，胶囊横向微展开展示 `好友 [名字] 正在游玩 [地图]`，显示 2.5 秒后平滑回缩。
  - **换图投票倒计时**：发起 Vote 时，胶囊左侧显示换图图标，右侧为剩余秒数与同意/反对占比微型进度条。
  - **网络健康感知**：检测到丢包、瞬时延迟飙升或断线重连时，灵动岛左侧呼吸提示黄/红警示圆点。

#### 2. 灵动岛悬停微控制
- **改进方案**：
  - 光标悬停至胶囊区域时，胶囊向两侧微膨胀展开，透出小巧的“上一首 / 播放暂停 / 下一首”媒体按钮，无需切换窗口即可快速切歌。

---

### 五、 设置与个性化易用性（Settings & Presets）

#### 1. 设置项全局搜索（Settings Global Search）
- **当前现状**：QmClient 与 DDNet 的配置选项多达数百项，分散在通用、外观、Tee、按键、QmClient、TClient 等多个主 Tab 及二级卡片中，玩家找寻特定功能时经常迷路。
- **改进方案**：
  - 设置面板顶部提供全局常驻搜索框（支持快捷键 `Ctrl + F` 聚焦）；
  - 输入关键词（如 `国旗`、`动效`、`字体`、`hitbox`、`开火`）时，实时过滤并高亮展示匹配卡片，点击条目平滑定位至目标卡片。

#### 2. 键位绑定冲突可视化提示（Keybind Conflict Visualizer）
- **当前现状**：玩家修改按键时，若将新操作绑定到已被占用的键位上，无法直接获得冲突反馈，往往进入游戏后才发现按键行为错乱。
- **改进方案**：
  - 绑定新按键时检测是否已被占用，若有重叠，按键框右侧显示橙黄色警示标记并提示：`已绑定到 [向左移动]，确认覆盖？`。

#### 3. “一键分享我的预设码”（Qm Profile Preset Sharing）
- **当前现状**：玩家之间分享 UI 配色、卡片排列或切枪动效配置时，通常只能依靠截图对照手工修改。
- **改进方案**：
  - 增加“导出预设”功能，将当前的 UI 颜色、卡片顺序、动效参数压缩为短字符预设码（如 `QM-CFG-k8F29a...`）；
  - 允许其他玩家一键粘贴应用，极大降低个性化门槛。

## 3. 技术可行性与性能约束

1. **动效引擎复用**：
   - 充分复用已有的 `QmAnimationBackend`、EaseOutBack 弹性曲线及 `UiTokens` 设计令牌，避免为单一特性引入孤立的动画状态机。
2. **零长帧与零额外内存分配**：
   - 所有运行时动效基于 `time_get()` 高精度时钟与当前渲染帧数学计算，不占用独立线程，不使用持续堆内存分配。
   - 动画结束后立即回到常数级只读分支，保证 144Hz / 240Hz 高刷下的极低 CPU 消耗。
3. **分级动效兼容**：
   - 所有新增视觉与入场动效严格受 `qm_ui_motion_level`（0=关闭，1=减弱，2=完整）控制，确保对低配置设备与无障碍辅助选项友好。

## 4. 推荐落地实施路线

| 阶段 | 重点推进方向 | 核心预期收益 |
| :--- | :--- | :--- |
| **第一阶段（短期高频）** | 弹窗与确认框对称式开闭动效、设置面板全局搜索（Ctrl+F） | 统一全端动效语言，消除最突出的查配置痛点 |
| **第二阶段（玩法强化）** | 局内打破纪录（PB）与通关微仪式、服务器地图悬停卡片 | 跑图正向情绪反馈拉满，找服找图成本大幅下降 |
| **第三阶段（特色生态）** | 灵动岛多场景事件胶囊、按键冲突检测、预设码一键分享 | 打造 QmClient 极具辨识度的招牌体验与社群传播力 |
