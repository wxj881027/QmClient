### 1.2 设置页现状（`menus_qmclient.cpp` RenderSettingsQmFunction 翻译段，约 1850-2356 行）

- 通用区常驻 9 行：自动翻译来信、翻译服务、目标语言、最小匹配字符、目标语言比例，LLM 时追加 Provider / API Key / Endpoint(optional) / Model / 并发滑条 + 有效并发说明行 / 思考开关 + 条件提示 / 自定义 prompt，出站区再追加 3 行（来源语言、发送目标语言、发送方式）。
- LLM 分支一屏最多 **12 类控件**，其中 Endpoint(optional)、并发、思考模式、自定义 prompt 属于低频/专家配置。
- 检测阈值（min chars / ratio）与所选后端无关，始终显示。
- 模型（Model）为纯文本输入框，无预设，易拼错；Endpoint(optional) 对内置 Provider 也显示，实际上内置 Provider 几乎不需要覆盖端点。

### 1.3 已有可复用模式

- 「Advanced options」checkbox + 条件渲染已在语音模块（`QmVoiceShowAdvanced`）与 HUD 通知模块（`QmHudNotificationsShowAdvanced`）落地，翻译模块未接入。
- 模块高度/布局依赖 ShowAdvanced 的解析函数已有先例（`ResolveQmHudVoiceHeight`）。

### 1.4 默认值现状与已知痛点

- 默认 Provider=0（智谱），模型默认 `glm-4.5-flash` / `deepseek-chat` / `gpt-4o-mini`；思考模式默认关。
- 智谱 flash 免费、国内直连，作为默认仍然合理；但各 Provider 的默认模型名随时间过期（如 glm-4.5-flash 是否仍为当前免费主力需在实现时核对官网）。
- 端点填写无防呆：填 base URL（少 `/chat/completions`）时请求打到站点首页，返回 HTML，报错不友好（2026-09-30 已在 `translate.cpp` ParseResponse 增加 HTML 检测提示，但未根治填写问题）。

### 2.1 跟进 LLM 的 AI 翻译默认项

| OpenAI | `gpt-5.6-luna`（$0.20/$1.20，最便宜当代）、`gpt-5.6-terra`（均衡）、`gpt-5.6-sol`（旗舰） | GPT-6 Astra 为最新旗舰但价格高（$10/$50），翻译场景不必；`gpt-4o-mini` 为 legacy 不再预设 |

#### 2.1.1 实施项

0. **紧急：默认模型名修正**（独立小改动，可先行发布）：三处 `MACRO_CONFIG_STR` 默认值更新为 `glm-4.7-flash` / `deepseek-flash` / `gpt-5.6-luna`；智谱免费档有效并发默认改为 1（免费 flash 档限 1 并发，现默认 3 会持续撞 429）。
1. **模型预设下拉**：Model 字段由文本输入改为「下拉预设 + 自定义输入」组合（复用 `RenderLanguageDropDownWithCustomInput` 的下拉+输入框组合模式），预设候选按 2.1.0 表；Custom Provider 保持纯文本输入。
2. **默认值刷新**：默认 Provider 维持智谱（免费、国内直连、官方推荐翻译场景）；模型默认名按 2.1.0 表，保证新用户开箱可用。
3. **并发默认微调**：并发智能默认联动预设档位（智谱免费档=1）；有效并发提示行合并进并发滑条行尾，删除独立说明行。

### 2.2 减少配置项 + 【高级】折叠

1. **新增 `QmTranslateShowAdvanced`**（bool，CFGFLAG_SAVE，默认 0），沿用 Voice 模块「Advanced options」checkbox + 条件渲染模式。
2. **常驻区精简为**：翻译服务、目标语言、LLM Provider（仅 LLM 时）、API Key、模型（预设下拉）。
3. **移入【高级】**：
   - Endpoint（Custom Provider 时例外：Custom 选定后 Endpoint 升为常驻，否则 Custom 无法配置）；
   - 并发滑条、思考模式开关、自定义 prompt；
   - 检测阈值（最小匹配字符、目标语言比例）；
   - 出站翻译的「来源语言」「发送方式」（「发送目标语言」保留常驻）。
4. **端点填写升级为「base URL + 接口格式自动识别」（根治工单的核心项）**：
   - **用户只填到 `/v1`**：端点字段语义改为 base URL（如 `https://api.ziliao.xyz/v1`，兼容不带 `/v1`、带完整路径的旧填法）。
   - **双格式支持**：请求层同时实现 OpenAI 两种接口——Chat Completions（`POST {base}/chat/completions`，现状）与 Responses（`POST {base}/responses`，`input`/`instructions` 请求体、`output_text`/`output[].content[].text` 解析）。
   - **自动识别**：新增接口格式选择（自动 / Chat / Responses，`QmTranslateLlmApiStyle`，默认自动）。自动模式下先试 Chat Completions，遇 404/405 或非 JSON 错误页时改试 Responses，成功后在会话内记忆该 base URL 的格式，避免每次双倍探测。
   - **多填容错（用户明确要求）**：粘贴的 URL 无论填到哪一层都要能识别——
     - 以 `/chat/completions`、`/v1/chat/completions` 等路径结尾 → 判定为 Chat 格式，剥掉已知路径后归一为 base URL；
     - 结尾容错：容忍尾斜杠、大小写、以及少写 `s` 的笔误（`chat/completion`），按子串匹配识别后同样归一；
     - 以 `/responses` 结尾 → 判定为 Responses 格式并归一；
     - 只到域名或 `/v1` → base URL，按接口格式自动模式处理；
     - 归一只在请求层做（`GetLlmEndpoint` 出口统一处理），不改存档内容，老配置零迁移。
   - **UI 呈现**：Endpoint 标签改为「API 地址（填到 /v1）」，占位文本 `https://api.example.com/v1`；格式选择放进【高级】（默认自动，绝大多数用户无需感知）。
5. **配置变量不删不改名**：只减少 UI 暴露，`concurrency_default` 等仅留 console 可调，避免存档迁移。

## 三、候选翻译服务扩展评估（2026-09-30 调研，未排期）

现状缺口：四个后端中，智谱/DeepSeek/OpenAI/腾讯云都要注册拿密钥，FTAPI 免 key 但公共服务不稳（UI 已有过载警告），LibreTranslate 需本地部署——「免注册 + 国内直连 + 稳定」三者交集为空。

| 候选 | 免费政策（2026 官方口径） | 注册门槛 | 国内直连 | 接入成本 | 小白适配评价 |
| --- | --- | --- | --- | --- | --- |
| **百度翻译** | 实名高级版 100 万字符/月，QPS=10（未认证标准版 5 万/月，QPS=1） | 百度账号 + 个人实名，APPID+SecretKey | ✅ 好 | 低：MD5 签名，双输入框，与腾讯云后端同模式 | **国内小白最优性价比**，28 语种覆盖游戏场景足够 |
| **DeepL API Free** | 50 万字符/月 | 单 API Key，无需实名，注册简单 | ⚠️ 不稳定（api-free.deepl.com） | **最低**：单个 POST + `Authorization: DeepL-Auth-Key` 头，无签名 | 海外/有代理玩家质量最优解；国内小白不推荐 |
| **MyMemory** | 匿名 5000 字/天（免注册免 key） | **零门槛** | ✅ 可达 | 极低：GET 请求即用 | 唯一「开箱即用」选项；质量一般、额度小，作免注册兜底 |

不推荐：有道智云（无长期免费额度，仅 50 元体验金）、火山/阿里云（强制实名 + 签名复杂）、Azure Translator（账号门槛高）、Google `translate_a/single` 等免 key 非官方接口（国内不可直连 + 封禁风险）。

另有一条不加后端的增强路径：LLM「自定义 Provider」升级为**预设一键填入**（如硅基流动：国内直连、OpenAI 兼容、送免费额度，选预设自动带出端点与默认模型），复用步骤 ③ 的 base URL + 双格式能力，小白也能用上 LLM 质量。

### 3.1 小白默认路径（核心设计原则：不上网站注册、不获取 key 最优先）

用户明确要求：**对小白来说，不上网站注册和获取 key 才是最方便的**。据此调整默认体验设计：

1. **开箱默认改为零 key 机翻**：`qm_translate_backend` 默认值由 `llm` 改为零 key 机器翻译（MyMemory 接入后设为其默认；落地前过渡期维持现状）。新玩家装完即可用，无需任何注册。
2. **LLM 降级为「质量升级」可选路径**：UI 在零 key 后端下放一行引导（如「想要更高质量？接入免费的大模型翻译 →」点击展开 LLM 配置区），并附各 Provider 的 key 获取指引链接；不再作为默认首屏。
3. **零 key 后端的定位**：MyMemory 为主（额度 5000 字/天，聊天短句场景足够），FTAPI 保留为备用；两者都免注册。
4. **限额降级行为**：零 key 服务达到当日限额或不可用时，聊天内提示一次并引导切换，不静默失败。
5. **优先级调整**：MyMemory 从「后续评估」提前为必做项，排在步骤 ② 之后、与 ③ 并行实施（互不依赖）；百度翻译/DeepL 仍为后续可选项。
