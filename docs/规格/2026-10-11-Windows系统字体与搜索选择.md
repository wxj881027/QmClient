# Windows 系统字体与搜索选择

状态：实现与自动验证完成，修改未提交；真实 GPU 与系统 IME 的界面验收待完成。

## 行为

字体卡片在 Windows 显示“显示系统字体”开关，配置名为 `qm_show_system_fonts`，默认关闭并保存。开启后，将 Windows 为所有用户及当前用户注册的 TrueType/OpenType 字体加入现有字体族列表，不复制或修改安装文件。

关闭开关只隐藏系统字体候选与样式，不撤销已选择的字体，也不清空保存的配置。下次启动会恢复仍然安装的已选系统字体；字体不可用时使用现有回退链。普通启动且没有需要恢复的缺失字体配置时不读取系统字体文件。

英文字体、中文字体及符号字体共用可搜索组合框。收起时仅显示当前字体与展开箭头，没有输入或清除按钮。点击展开后自动聚焦弹层顶部的唯一搜索输入框，支持中文及忽略大小写的名称片段筛选。上下键选择候选，回车补全并应用；任意未识别文字不直接写入字体配置。无结果时保持输入，显示现有“无结果”文案。ESC 或点击外部取消草稿、释放输入焦点，重新打开时清空搜索。中文 IME 组合期间，方向键与回车由输入法处理。

中文候选仍使用现有 CJK 字形筛选。字体样式与可变字重维持既有选择方式，字体预览沿用共享下拉实现。

## 实现与边界

`src/engine/client/qm_system_fonts.h` 读取 Windows 字体注册记录，处理系统目录中的文件名、当前用户目录中的文件名、完整 Unicode 路径和环境变量路径。仅接受 TTF、OTF、TTC、OTC；无法解析的相对路径、网络路径与网络映射盘不进入同步读取。

`src/engine/client/text.cpp` 继续先加载游戏字体目录，再加载系统字体；同内容去重，保留现有字体名称与样式解析规则。字体字节和 face 由文字引擎拥有，保持到引擎关闭，避免隐藏候选破坏已有字形与预览引用。已成功读取的系统文件在重载时复用。将同内容字体复制到游戏字体目录后，该字体成为普通候选，不受系统开关隐藏。

`CQmDropdownSearch` 保留筛选结果到原始候选的索引映射，缓存未变化的输入与来源。字体卡片通过共享下拉的搜索属性启用组合框。普通下拉保留原行为，可搜索弹层允许零结果而不关闭。

本功能不安装字体，不修改 Windows 字体注册表，不修改 DDNet 存档或字体配置值的格式。字体卸载后的跨进程恢复使用现有回退策略；当前会话已经加载的字体仍可使用，直到退出。
