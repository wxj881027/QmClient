# 服务器列表拆栏与预览、灵动岛事件、公告通知——实施方案

输入：用户校准（2026-10-14）。砍掉：通关状态列、好友上线入灵动岛、资源下载完成事件（DDNet 无此场景）。

## 一、服务器列表拆栏 + 简短服务器名（先行）

### 1. 简短服务器名（默认开，仅国服生效）

- **国服判定**：按社区 id 集合（复用 CCommunityIcons 的社区体系；首版集合 = chn/ddnet-cn 系，随社区配置可扩）。仅命中集合的服务器应用短名规则。
- **短名规则（首版解析器，逐条可校准）**：剥前缀标签 `[xxx]`/`(xxx)` → 压缩连续空白 → 截断到首个 `|`/`-` 分隔符 → 尾部序号保留。例：`[CHN5] 上海 · DDNet 官方` → `CHN5 上海`。
- **配置**：`qm_ui_server_short_names`（默认 1）；解析失败的行回退原名，永不显示空名。
- **落点**：浏览器列表行渲染处新增 `ShortenServerName()`（menus_browser.cpp），原 `m_aName` 不改、仅显示层替换（排序/收藏/连接仍用全名）。

### 2. 拆栏（难度 / 服务器名 / 地图名）

- 现状：难度星级以 `FormatMapDifficultySuffix` 拼在地图名后（CQmMapDifficultyCatalog 已有目录与 ★ 文案）。
- **拆分**：地图名后缀拆除 → 独立「难度」列（简单图 + ★…；无目录条目显示 `--`）；「服务器名」列用短名；「地图名」列保留原名并作为预览挂点。
- 列宽分配随 UI 缩放走现有 browser 列布局；窄视口优先保服务器名可读（截断加省略号）。

## 二、地图悬停/右键预览弹窗（接二级菜单组件）

- **触发**：地图名列悬停 200ms（防扫过频闪）或右键菜单项「预览地图」。
- **弹窗载体**：接入二级菜单弹层栈（DoPopupMenu 锚定模式）——这是对二级菜单能力的增强点：现有锚定弹层以文本条目为主，新增**富内容锚定弹窗**封装（pfnFunc 任意渲染本就支持，封装成可复用的「预览卡」形态：锚定列旁、满幅布局揭示裁剪、复用统一抽屉语言）。
- **内容**：地图缩略图（CMapImages 仅查本地已缓存地图，**未缓存不联网**，显示骨架占位+「进入服务器后可预览」提示）+ 地图名/类型/玩家数。
- **缓存**：缩略图渲染句柄 LRU，悬停多次不重渲染。

## 三、灵动岛：仅连接状态事件（Phosphor 图标）

- **范围**：连接状态变化接入岛队列（连接中/已连接/断开），图标用 Phosphor `cell-signal-low/medium/high` 按连接质量分档（qm_icon.h 已有码位与 Fill 字面基建）；**不做**资源下载完成（场景不存在）、**不做**好友上线（会冲爆岛）。
- 落点：hud_media_island_logic 事件队列（入队/去重/静默期）+ 各事件源逐个接（首版只接连接状态）。

## 四、好友进服 / DDNet 服务器公告 → toast/公告区

- 好友上线提示**维持现状**（聊天框处），不入岛。
- 新增接入 toast/公告显示区的通知：好友进服、DDNet 服务器公告（现有公告文案来源不变，仅渲染出口升级）。
- **聊天框优化另立专项思考**（历史翻查、表情输入、字号、频道过滤——UX 方案维度二底稿），本批不动。

## 五、好友跟随引导（仅方案，暂不实施）

见 2026-10-14 会话：满员好友服「等待空位」→ 单服后台刷新（15s 可配）→ 空位经灵动岛提醒一键加入；完整档（自动连接开关/重试/上线广播）后续可选。依赖三节的岛事件队列先落地。

## 实施顺序

A 简短名 → B 拆栏 → C 预览弹窗（1+2 同域先行）；三（岛连接状态）与四（toast 公告）随后。风险点：短名解析依赖真实服务器命名样本（需抽样校准规则）；预览弹窗注意与现有右键菜单的冲突处理。
