当前实现调整：

- 地图列图标点击打开居中的共享二级面板，标题、关闭按钮、服务器类型与人数、实体开关、操作提示在面板内排版；地图画布嵌入内容区，不覆盖标题或提示。

- 相机或实体模式改变时按当前视野重绘 1024 宽离屏目标，静止时复用；取消整图纹理 UV 放大，避免越放越糊。实体模式使用能渲染实体的前景策略，贴图模式继续完整设计策略。

- 预览六条文案进入 TOML 与语言生成链。完整扫描额外揭示基线九条滚动/服务器列配置文案缺译，属于既有翻译缺口；本任务不修改覆盖策略。

截图返修补充：静止帧也会合成缓存目标，Vulkan 原合成入口只执行 secondary 命令缓冲，却直接向仍采用 secondary 模式的 primary 通道绘制；后续菜单可能重置已执行的 secondary，造成好友区、底部控件和预览标题丢失。合成入口现先结束 secondary 通道并以 LOAD 恢复 inline 通道，后续绘制留在 primary；执行 secondary 后同步清空 primary 的绑定缓存。新增通道切换与失败中止行为测试。此前仅清绑定缓存的修复未解决用户截图问题。

## 一、服务器列表拆栏 + 简短服务器名（先行）

### 1. 简短服务器名（默认开，仅国服生效）

- **国服判定**：按社区 id 集合（复用 CCommunityIcons 的社区体系；首版集合 = chn/ddnet-cn 系，随社区配置可扩）。仅命中集合的服务器应用短名规则。
- **短名规则（首版解析器，逐条可校准）**：剥前缀标签 `[xxx]`/`(xxx)` → 压缩连续空白 → 截断到首个 `|`/`-` 分隔符 → 尾部序号保留。例：`[CHN5] 上海 · DDNet 官方` → `CHN5 上海`。
- **配置**：`qm_ui_server_short_names`（默认 1）；解析失败的行回退原名，永不显示空名。
- **落点**：浏览器列表行渲染处新增 `ShortenServerName()`（menus_browser.cpp），原 `m_aName` 不改、仅显示层替换（排序/收藏/连接仍用全名）。

### 2. 拆栏（难度 / 服务器名 / 地图名）

- 现状：难度星级以 `FormatMapDifficultySuffix` 拼在地图名后（CQmMapDifficultyCatalog 已有目录与 ★ 文案）。
- **拆分**：地图名后缀拆除 → 独立「难度」列（简单图 + ★…；无目录条目显示 `--`）；「服务器名」列用短名；「地图名」列保留原名并作为预览挂点。
- 列宽分配随 UI 缩放走现有 browser 列布局；窄视口优先保服务器名可读（截断加省略号）。

## 二、地图悬停/右键预览弹窗（接二级菜单组件）

- **触发**：地图名列悬停 200ms（防扫过频闪）或右键菜单项「预览地图」。
- **弹窗载体**：接入二级菜单弹层栈（DoPopupMenu 锚定模式）——这是对二级菜单能力的增强点：现有锚定弹层以文本条目为主，新增**富内容锚定弹窗**封装（pfnFunc 任意渲染本就支持，封装成可复用的「预览卡」形态：锚定列旁、满幅布局揭示裁剪、复用统一抽屉语言）。
- **内容**：地图缩略图（CMapImages 仅查本地已缓存地图，**未缓存不联网**，显示骨架占位+「进入服务器后可预览」提示）+ 地图名/类型/玩家数。
- **缓存**：缩略图渲染句柄 LRU，悬停多次不重渲染。

## 四、地图预览：交互与数据策略（用户问答 2026-10-14）

**数据有效性（回答「只对已下载地图有效？」）**：是——预览只渲染**本地已缓存的 .map**（下载过的地图在 maps 目录）；悬停**绝不触发联网下载**。未缓存地图显示骨架占位 +「进入服务器后可预览」。可选增强（后续、默认关）：社区 HTTP 缩略图源。

**缓存与性能**：
- 悬停 200ms 延迟窗内完成解析：低分辨率离屏渲染（~512px 纹理），耗时 10~50ms 可接受；纹理 LRU 缓存（key=地图名），重复悬停零成本
- **拖拽平移**：点击拖拽 = 纹理 UV 偏移，零额外渲染成本；默认整图适配预览框
- **实体层显示**：GAME/FRONT 层瓦片合成渲染（DDNet 标准 map view 观感），开关记忆配置
- 命中风险：解析放悬停延迟窗内同步做，超帧预算（>50ms）转下一帧分片，避免卡顿
