# 移动端观战端适配

状态：进行中。

已落地：页签裁剪（只隐藏 TClient）、字体卡片并入画面页、内容区触控滑动滚动（含惯性、跟手增益 1.5）、移动端设置字号整体放大 1.35 倍。前四项已构建进 APK 并在模拟器安装；字号放大与配套单测因本次会话的 shell 失去工作区写权限（`mkdir`/`touch` 全盘 Permission denied，`tools.write` 正常）未能编译验证。

其余条目待实现。

## 目标

手机端不是桌面端的缩小版，而是专门的**观战 / 回放端**：进服即旁观、触控操作、界面为大屏触摸重排，桌面专属能力一律不呈现。

## 一、设置页签裁剪

判定集中在 `SettingsPageHiddenForMobile(Page, MobilePlatform)`，通过 `SettingsPageVisibleInRightTabBar()` 生效；`MobilePlatform` 显式传参，桌面单测可直接覆盖判定表。隐藏的页也不能成为落地页，`RenderSettings` 里回落到通用页。

| 页签 | 手机端 | 说明 |
| --- | --- | --- |
| 通用 | 保留 | 语言、Demo/视频目录、更新率；收起自动录像/截图/CSV |
| 皮肤（Tee） | 保留 | 观战要看别人的皮肤 |
| 外观 | 保留 | 名牌、拖尾等观战观感 |
| 控制（绑键） | **保留** | 手机没有键盘，绑定是独立入口 |
| 画面 | 保留 | 画质与缩放；TClient 的字体卡片并入此页 |
| 声音 | 保留 | |
| 资源 | **保留** | 游戏内录制与观战片段的来源 |
| DDNet | **保留** | 官方设置 |
| TClient | 隐藏 | 桌面兼容向；字体卡片移到画面页 |
| QmClient / 搜索 / 贡献者 | 保留 | |

## 三、待实现

### 1. 触控滚动（当前完全缺失）

`CScrollRegion`（`src/game/client/ui_scrollregion.cpp`）只有两条滚动路径：滚轮，以及**拖动滚动条滑块**（`BeginThumbDrag`）。内容区按住拖动不会滚动，这在手机上等于不会用。需要新增：

- 内容区按下 → 跟随手指位移滚动（`SetOffset` 按手指增量）；
- 松手后惯性衰减，越界回弹；
- 与列表项的点击判定互斥：位移超过阈值即取消点击；
- 与双指捏合、摇杆等已有手势的优先级关系。

服务器列表、设置卡片、Demo 列表、资源列表都走同一套，改 `CScrollRegion` 一处即可全覆盖。

### 2. 界面尺度

- 字号整体上调（移动端最小字号与行高），设置卡片、列表行高同步放大；
- 服务器列表按移动端重排：更大的行高、更少列、关键信息（人数/延迟/难度）保留；
- 设置页左栏改成**可折叠目录**（分组标题 + 展开/收起），避免页签过多需要滚动。

### 3. 观战交互

- **触控轮盘移动视野**：现有摇杆是移动/相机推进，需要一个能连续平移自由视角的轮盘；
- 进服即加入旁观：已实现，需在移动端回归验证；
- **底部灵动岛**：显示当前旁观者信息，仿照现有顶部灵动岛实现（`QmCardCatalogHud*` 里的 `qm:dynamic_island`）。这是新组件，不是改现有卡片。

### 4. 入口与统计

- 去掉顶部地图编辑器入口（手机端不提供编辑器）；
- 统计页把“游玩时长”改成“观战时长”。

## 四、顺序建议

1. `CScrollRegion` 触控滚动（影响面最大，一处改动全站受益）；
2. 界面尺度与折叠页签；
3. 服务器列表重排；
4. 底部灵动岛（新组件，依赖尺度确定）；
5. 轮盘移视野、隐藏编辑器入口、统计口径。

## 五、验证

- 单测：页签判定表（已具备，`SettingsMobilePages.*`）、滚动状态机的滑动/惯性/取消点击、统计时长口径。
- 模拟器：能用鼠标与 `adb` 触摸两种方式操作后再做截图验收。当前 `adb` 注入的触摸坐标与画面坐标不一致（点到编辑器/服务器浏览器而非目标控件），需要先解决输入映射，否则移动端交互无法自动验收。
