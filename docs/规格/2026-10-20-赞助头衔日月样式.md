# 赞助头衔日月样式

状态：实现与回归测试代码已补充，未编译、未运行测试，客户端实际显示和跨客户端同步待验证。

## 玩家行为

- 赞助头衔改为围巾兔、用户文字和天体底纹组成的胶囊，宽度随文字变化。
- 月亮与太阳共用星轨、圆角和图标比例。游戏内采用设计的深色底方案；月亮默认为紫色，太阳默认为金色。
- 外观设置只有样式、整体颜色和透明度。配色联动底色、描边、图标、底纹和文字；透明度作用于所有图层。
- 从默认配色切换日月时使用对应默认色；自定义配色在切换样式时保留。
- 预览即时反映草稿。点击保存后提交文字、昵称绑定、聊天特效和外观，其他客户端通过中心服务取得相同外观。
- 保留兑换、用户文字输入、昵称绑定、聊天特效、本体与分身显示、名牌显示和位置开关。
- 开发者专属徽章继续使用原入口；聊天历史保存消息到达时的头衔和外观，避免玩家槽位复用后改变旧消息。

## 设计与实现

设计来源：[Figma 日月头衔](https://www.figma.com/design/PLKOMmnaRuNZxKVhGGk2vr/QmClient?node-id=11-185)。原轨道矢量改为四段星轨，补充太阳、浅色与深色对照和对应围巾兔配色。

`data/qmclient/title_badges/` 保留 Figma 导出的 SVG，PNG 是供现有纹理管线使用的白色蒙版，文字由客户端字体实时绘制。底纹分三段绘制，两端不随文字宽度一起拉伸；名牌和聊天共用外观、尺寸与表面绘制接口。

外观配置使用 `qm_title_badge_style`、`qm_title_badge_color` 和现有 `qm_title_opacity`。旧外观配置仍可读取，日月头衔不再使用旧的彩虹、浮动、掠光和辉光参数。

## 中心服务通信

资料接口和在场快照增加可选对象：

```json
{"appearance":{"style":"moon","color":9790138,"opacity":100}}
```

- `style` 为 `moon` 或 `sun`；`color` 为 0 至 16777215 的 RGB 整数；`opacity` 为 0 至 100 的整数。
- 服务端将外观与认证用户资料一起保存，HTTP 资料响应和 WebSocket 在场快照同时携带该对象。
- 旧资料没有外观时返回默认月亮紫色，不批量改写原始数据库。
- 旧客户端不提交 `appearance` 时保留原值；无效对象拒绝整次更新。
- 新客户端收到缺失或无效对象时整体回退到默认外观；旧服务不支持外观保存时显示明确提示。
- 昵称、服务器地址、租约、隐私和分身可见性继续沿用原判定。

服务实现位于独立仓库 `qmclient_scripts/qmclient_center_server/`，对应 [服务端 PR #6](https://github.com/wxj881027/qmclient-center-server/pull/6)，不将其已有未提交工作纳入客户端提交。
