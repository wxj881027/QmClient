# 当前阶段

`CQmI18n` 定义窄 lookup/fallback 接口：feature 通过稳定 key 和可选 context 请求文本，找不到翻译时返回调用方提供的 fallback。lookup 只保存无状态函数指针，不保存裸 `void *`，也不复制 DDNet 的语言加载、字体或文本缓存系统。

runtime 初始化时把该接口绑定到官方 `Localize`，因此 Qm feature 不需要直接依赖语言数据库；旧 UI 和新 UI 都可以通过同一个 feature/card model 读取文案 key。`Text` 对空 key、空 context 和空翻译均有 fallback 行为。

当前已完成接口和官方 lookup 接线，但尚未接入 Qm 文案 source、语言切换通知、生成产物和重复 key 审核。后续 source 统一放在 `translations/i18n/qmclient/*.toml`，语言 txt 只作为生成物；接入前必须补齐 source、消费点、fallback、语言切换和资源生命周期台账。

## 验证

- `QmI18n.UsesLookupAndFallback` 覆盖 lookup、缺失 key、空 key、context 覆盖和 fallback。
- Release `run_cxx_tests`：371/371 通过，3 个既有 disabled。

## 未完成

- Qm 文案维护源和生成流水线尚未迁回本分支。
- 尚无真实旧 UI/新 UI presentation 调用点；当前 model 只提供共享的 descriptor 和状态读取边界。
