## 它是什么
DDNet 页里没归进其它卡的客户端杂项：timeout code 的种子、进服后自动执行的命令，以及 Windows 上卸载协议与文件扩展名注册。

## 机制
timeout code 不是存下来的固定串：客户端用种子加上本次连接的目标地址做摘要，再生成密码，所以每台服务器的码都不同，种子不变码就不变。换种子会用新的随机密码覆盖它，之后所有服务器的码同时改变，服务器按昵称记住的旧码随即对不上；种子为空时客户端会在连服前自己生成一个。进服命令在握手后发的第一条聊天包里，与表情、dummy 相关设置拼在同一包，用分号分隔，因此可以串联多条，只发一次。卸载注册只动注册表里的协议与文档关联，不删除客户端文件。

## 调到合适
1. 进服命令只写最常用的一两条，用分号串联；字段长度有限，堆太多会被截断。
2. 只在昵称被占或认证异常时换种子，换完记得重新登录一次。
3. 确实不再需要浏览器拉起客户端时才点卸载注册，出问题只能重装或重新注册。

## 注意
- 种子一换，本地保存的旧码无法恢复；想留退路就先记下配置里的 `cl_timeout_seed`。
- 进服命令以普通聊天包发出，服务器按消息内容当命令解析，写错一个字符就是一条普通发言。
- 这里的选项已经跨到网络行为，先在测试服验证，别直接带进比赛。
- 卸载注册只在 Windows 上出现，其它平台看不到这一项不等于功能被砍。
