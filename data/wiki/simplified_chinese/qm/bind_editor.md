## 它是什么

设置 → 控制 → Bind 的「键盘与鼠标」卡片：把一条命令、或一串命令，写到某个键上。界面按真实键盘排列，鼠标键与四个滚轮方向在键盘下方，已绑定的键帽有高亮。

## 一条绑定由三部分组成

`bind <键> "<命令>"`

- **键**：字母数字直写；小键盘加 `kp_` 前缀；鼠标是 `mouse1`、`mouse2`、`mwheelup`。
- **修饰键**：`ctrl`、`alt`、`shift`、`gui`。`gui` 就是 Windows 键、macOS 的 command、Linux 的 super；组合写成 `ctrl+s`。
- **命令**：可以只有一条，也可以是一串。

## 一串命令怎么写

用分号分隔，整体用引号包住：

```
+fire; +toggle cl_dummy_hammer 1 0
```

**分号不是顺序执行。** 同一帧内全部执行，没有 sleep、delay、wait 这类命令。想让动作分先后，只能拆成不同的键，或者用 cfg 一个文件一个文件地 `exec`。

## 三种切换

| 写法 | 按下 | 松手 |
|---|---|---|
| `toggle 设置 值A 值B` | 换到另一个值 | 不变，再按才换回 |
| `+toggle 设置 值A 值B` | 写入值A | 写入值B |
| `+toggle_restore 设置 值` | 写入值 | 恢复按下前的原值 |

三者都**只能用于客户端设置**（`cl_`、`inp_`、`gfx_` 这类），不能用来切换命令。`+toggle_restore` 是本客户端的扩展，适合临时改灵敏度又不弄丢原值。

## 引号、嵌套与长度上限

命令串里再写 `bind` 需要转义引号，每深一层反斜杠翻倍：

```
bind x "bind y \"+jump; bind z \\\"echo deep\\\"\""
```

超过 5 层控制台直接报错。日常不建议手写嵌套，拆成 cfg 更清楚。

整条 `bind` 行（含键名、引号、转义）上限 **16384 字节**，超过时编辑器拒绝写入；从控制台手打时还受 512 字符输入行限制。

## 怎么调

1. 点键帽选中；先勾顶部修饰键再点主键，就是组合键。
2. 右侧「已绑定功能」列出这个键上的每条命令，可逐条删除。
3. 「添加功能」从预设或已注册命令里挑，也可以自己输；按「添加」写入。
4. 「捕获」把整个绑定搬到新键；捕获到空键等于清掉这个绑定。

## 写完先验一次

保存只检查**语法**——引号是否闭合、括号是否配对，不检查命令名是否真的存在。名字写错不会有任何提示，直到按下才发现没反应。

最稳的验证：关掉设置按一下；或在控制台输入 `binds <键>`，它会打印这个键当前绑了什么。

## 常见错误

| 现象 | 原因 |
|---|---|
| 按了完全没反应 | 命令名拼错，或该命令只在特定模式 / 服务器有效 |
| 松手后状态没恢复 | 用了 `toggle` 当成按住用，应换 `+toggle` |
| 关闭后假人一直挥锤 | 关的那一侧没把 `cl_dummy_hammer` 归零，官方 deepfly 教程专门提醒过这个坑 |
| 原来的键不能用了 | 同一键位后写覆盖先写，改完去「绑定一览」核对 |
