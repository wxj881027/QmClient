## 它是什么

聊天翻译层：把收到的聊天送去翻译服务，译文挂回那条消息；也能在自己发言前先译一遍，只发译文。它只改你看到的文字和真正发出去的内容。

## 在对局里

收到的消息先在本地判语言：字数太少或目标语言占比够高就不送翻，占不占额度靠这两个阈值（「最少匹配字符数」默认 2、「目标语言比例」默认 75）控制。命中后进异步队列由 HTTP 后端请求，译文回来写回那条聊天行；那行已被聊天环形缓冲挤掉就放弃。翻译失败时那条行上会显示本地化的错误提示。

发送方向在真正发出前完成翻译，只有译文会上服务器；勾着「在出站译文下方显示原文」（默认开）时原文以附注留在你本机。翻译失败时整条不发，你会在聊天里看到错误提示，原文不会兜底发出。

## 怎么调

1. 开「自动翻译收到的聊天消息」，「收到消息译为」选你常读的语言（默认 zh）。
2. 「翻译服务」挑一个：MyMemory（默认，免注册匿名日额度）、腾讯云、DeepL、百度、LibreTranslate、FTAPI、自动链路、LLM。每个服务一套凭据，换服务要重填：腾讯云要 SecretId/SecretKey，百度要 APP ID 和 key，DeepL 要 API key，LLM 按提供商各填各的 key。LibreTranslate 和自建服务可以不填密钥。
3. 填完用「测试翻译」验链路，它只发一句固定英文短句；开了「翻译诊断」会多显示服务名和 HTTP 状态。
4. 要发出去也翻译，再开「自动翻译发送的聊天消息」，单独设「发送消息译为」（默认 en）。
5. 「高级选项」里有 LLM 并发（0=自动，智谱免费档只有 1）、接收/发送翻译方式（只在需要时翻还是始终翻）等。

## 注意

- MyMemory 超日额度只提示一次，之后一分钟内静默；单句超 500 字节不送翻。
- 并发到顶时后来的消息直接跳过，不会排队补译。
- FTAPI 是免费公益服务，自动翻译默认禁用，要手动在卡里打开；滥用可能导致服务不可用。
- LLM 换模型或换端点后同样用「测试翻译」验证。
