## What this controls

The input box at the very top of the settings page. It searches all setting cards by keyword, and the line below shows "Found N global cards".

## In game

Use it to flip a switch mid-game without paging around: no Enter needed, results change as you type. It matches card names, descriptions, search terms, and every control's config name and Chinese label, so typing a qm_ config name or the English original also hits.

## Watch out

It matches whole substrings only and does not split words: a space between two words breaks the match, only a contiguous string can hit.

It finds cards, not individual switches — a dozen options inside one card come out together.

When you return to the search page the input box is focused and selected, so typing directly overwrites your last keywords.
