## What this controls

The two mouse sensitivities and two cursor distance limits. Sensitivity is a multiplier: how far the crosshair travels for the same hand movement. The two distances decide how far from the Tee the crosshair may go, and how close it must stay.

## In game

Sensitivity changes the feel directly: double the value and the same hand movement turns the crosshair twice as far. After switching mice or changing system DPI, the same value feels different and needs remeasuring.

Both distances are visible on screen. Maximum cursor distance cages the crosshair inside a radius — pushed outward it just stops; with Minimum cursor distance above 0, the crosshair can never touch the Tee. Both push it along its current direction, so the aim angle never changes.

## How to tune it

"Ingame mouse sens." defaults to 200 and only accepts 1–500. Change by 10–20 at a time and test in a warmup map. If 1 still feels too fast or 500 still too slow, system DPI is the only thing left.

"UI mouse sens." only moves the pointer in menus and console — a separate value from in-game aiming, tuned on its own.

Both distances default to 0 and 400 and usually need no changes. Narrow them only if the crosshair draws too far out, or close-range fights jitter uncomfortably.

## Watch out

With "Dynamic Camera" on, these two distances no longer govern the crosshair; the dynamic camera's own limits take over, and the card values remain but do nothing.

In free spectate, not following any player, the crosshair escapes both limits and clamps to the map border instead.
