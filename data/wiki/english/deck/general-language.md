## What this controls

The interface language: which script menus, settings entries and client messages use. Player chat and server rules are unaffected.

## In game

One click switches it, no restart needed. The whole interface re-lays out; languages like Chinese switch to a font with the matching glyphs. Card titles change too — from then on, find cards by their new translated names.

## Watch out

The list sorts by each language's own name, first entry English; selecting it clears the language setting and returns the interface to plain English. Entries still partly English are untranslated, not load failures.

Editor changes apply only after leaving the editor.
