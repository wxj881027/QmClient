## What this controls

Chat box display layer: showing, staying, whose messages appear, font size, width, line spacing, background color, draft and chat log saving. It decides how chat is drawn and stored, not how messages are sent or received.

## In game

Off "Show chat" and chat disappears. Without "Always show chat" it shows on new messages or the chat key, then tucks away; tick it and chat stays.

"Show names in chat in team colors" colors names by team, telling teammates from opponents at a glance.

"Use old chat style" reverts to the old look without background or Tee heads; background color and rounding below stop working.

## How to tune it

Decide how it shows first, then set a width you can scan in one glance and let font size follow; they pull against each other, one change can push the other back. Line spacing last, 2 to 6 px.

Stack filters as needed: friends-only and team-only intersect; "Only show messages related to me" takes over once on, leaving your own lines, whispers and mentions; system notices still show.

| Item | Effect | Cost |
| --- | --- | --- |
| Font size | Line height | Bigger, harder to scan |
| Width | Wrapping and covered area | Wide blocks view |
| Line spacing | Space between lines | Too large looks hollow |
| Auto save chat log | Daily local files | Files keep growing |

## Watch out

"Chat log retention days" only appears while "Auto save chat log" is on; expired files are cleared. Replays write no log; with streaming profanity filtering on, written content is replaced.

The log stores received text as-is: messages blocked by friend, team or related filters are still written in; not seeing them in chat doesn't mean they aren't in the file.
