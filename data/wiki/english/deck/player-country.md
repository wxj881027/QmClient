## What this controls

Flag for you and your dummy: player_country on the main tee, dummy_country on the dummy, ISO numeric codes. The default -1 is the resource pack's placeholder flag; display only.

## In game

The flag beside each name on the scoreboard; whether others draw it depends on their client, but the value is submitted to the server.

## Watch out

Cells show codes like CN or DE; the search box filters by those letters only.

Selections are sent when you close the settings menu.

First open decodes all flags on the fly, so some cells stay empty briefly, and a cell whose flag is not ready shows no code either.

An invalid code in the config falls back silently to the placeholder flag.
