## What this controls

Commands in the bind table that no known action claims land on this card; the row name is the raw command. It has no fixed content — it depends entirely on which binds you carry.

## In game

Common sources are binds left behind by other clients or older versions, plus hand-written binds you typed into the console yourself. Those commands may still work today, or may not exist in this client at all; the card only lists them so you can rebind or delete.

Rows sort alphabetically by command, and the card starts collapsed. The row count moves: delete the last bind of this kind and the whole card disappears with it.

## How to tune it

1. Hover over the row name first to read the full text — long commands are truncated, and only the hover shows the complete raw command.
2. If you cannot identify one, keep it but move the key somewhere you rarely press; do not let it eat a key you use often.
3. Certain it is useless? Clear the slot: click the trash icon at the end of the row, or right-click the slot. While the same command still sits on another key, the entry stays.

## Watch out

Being on this card does not make a command valid: when the client does not recognize it, pressing does nothing in game except a local echo that the command was not found.

The command is compared against the known action table as one whole string; one character off in spelling or case and it never joins a named category.

Rebinding only swaps the key, not the command text, so a new key will not turn it into a known action.
