## What this controls

Draws the current chat appearance as a small set of sample messages, so you can see how font size, width, line spacing and colors land. It saves nothing; change a setting and the samples follow.

## In game

The samples, in order: system join message, mention, team, friend, spam, client echo. How many show follows the filter switches above — turn system messages off and the first line disappears. Line width uses the smaller of "Chat width" and the space the card has, so wrapping matches the in-game chat.

The [6] after the spam line marks how many times it repeats; with "Use old chat style" on, the background and the Tee heads here vanish too.

## Watch out

Samples use your own name and a few fixed skins; other players' messages will differ with team, friend status and how IDs are shown.

There is no input box, no translated sub-line, and no scrolling — to see the real thing, join a server.
