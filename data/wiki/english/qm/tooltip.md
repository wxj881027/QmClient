## What this controls

Choose the tooltip font size and bounce animation. Tooltips use the popup background color and opacity and the interface text color.

## In game

Any control with a description in the menus pops a bubble on hover: the text uses the size chosen here. With "Tooltip bounce animation" on, the bubble fades in while scaling up from slightly smaller, over about 0.2 seconds; with it off, the bubble just appears — the same when the interface motion level is Off. The bubble prefers the area above the anchor, flips below when it does not fit, then sticks to either side, always on screen.

## How to tune it

1. Adjust the font size while watching the preview.
2. Use “Reset tooltip appearance” to restore the default size and animation.

## Watch out

- Bubbles in the settings pages follow this font size too, but skip the entrance animation: they appear instantly in the compact layout.
- The preview is a single line; long descriptions still wrap or get cut off. Do not judge long sentences by it.
