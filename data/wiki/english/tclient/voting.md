## What this controls

Votes on map votes automatically for you: the moment a map-change vote starts, it agrees or rejects per your setting, and can post a chat line along with it. Map votes only — kick, pause and the like still need a manual press.

## In game

- It is not waiting for you to walk away; it is waiting for the map to run long: only when game time plus warmup time reaches "Minimum time" does it act — hence "when far".
- It only handles votes with a countdown, and only while you are not AFK; kick votes, pause votes, map-change cooldown votes, category checkbox votes and funvotes are never touched.
- When the initiator is identifiable (0.7 servers): votes started by yourself, a friend or a teammate (team not 0) get no automatic stance — press it yourself if you want to weigh in. On 0.6 servers the initiator is unavailable and the exemption does not apply.

## How to tune it

- "Auto map vote" has three levels: Off / Auto agree vote / Auto reject vote (off by default). Pick Auto reject vote if you do not want map changes to pass; Auto agree vote if you want to go along with them.
- "Minimum time" is 1–20 minutes (default 5): map-change votes started below that duration are not touched.
- "Message to send in chat:" posts one extra normal chat line after voting; leave empty for none.

## Watch out

- Map votes under the minimum time are silently skipped — that is not a malfunction.
- The extra line goes to public chat, where everyone can read it.
- The compact vote bar belongs to "Show compact vote HUD" on the HUD card, not this card.
