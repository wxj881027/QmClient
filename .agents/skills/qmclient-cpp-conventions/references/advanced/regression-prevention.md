# 回归场景参考

为容易复发且值得维护的问题选择真实可执行的回归方式，验证范围统一按 `qmclient-verification-gate`。

- parser、迁移、状态机、生命周期决策和跨语言日志合同优先用确定性行为测试。
- UI、原生输入、音频和设备行为按需记录手工步骤、预期结果及失败信号；截图只证明实际观察到的状态。
- 性能对比使用同环境、同操作、同指标的基线；不同场景不能直接作严格回归结论。
- 复用现有 fixture、测试数据和活动计划；不为满足文档创建空地图、demo 或配置目录。
- 测试应能在目标行为回归时失败；源码字符串检查只用于确有必要的接线约束。

发布风险审查仅覆盖此次影响的模块和平台，记录未解决 findings 与实际缺口。Release 文案由 `qmclient-git-commit` 维护，不在本参考重复定义分类和检查流程。
