# 安全与数据边界工作流

本文件用于文件系统、下载、解压、日志、用户反馈包、外部输入、配置导入导出和隐私相关任务。

## 基本原则

- 外部输入默认不可信。
- 用户路径、下载内容、压缩包内容和配置文件都要校验。
- 日志和 debug bundle 必须脱敏。
- 失败要可见，不要静默吞掉。
- 安全修复优先于体验优化。

## 文件与路径

- 规范化路径后再判断是否位于允许目录内。
- 解压时拒绝绝对路径、`..` 穿越和覆盖关键文件。
- 写文件前确认目录意图，避免写到游戏根目录或用户未知位置。
- 删除或移动文件必须范围明确，不能用模糊 glob 做递归破坏性操作。

## 网络与下载

- 校验 URL、大小、类型和目标路径。
- 下载失败要保留明确状态。
- 不要把网络结果直接发布到 UI 或资源系统；先经过验证和 fallback。
- 缓存损坏时回退 source/live 路径，不阻塞页面。

## 日志与反馈包

debug bundle 不得包含：

- token、密码、认证 header。
- 私密聊天内容。
- 完整服务器历史和个人标识信息。
- 未脱敏的本机路径，除非用户明确同意。

应包含：

- 客户端版本、平台、renderer。
- 脱敏配置。
- perf summary、net summary、prediction summary。
- 最近 warning/error 摘要。

## 验收

按变更边界选择失败路径或恶意输入测试；涉及日志、配置导出和反馈包时检查脱敏。验证命令与提交前检查遵循 `qmclient-verification-gate`，修复已确认的安全 finding 后交付。
