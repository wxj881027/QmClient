# QmClient 代码审查

读指定 diff/模块、直接调用点与已有保护，优先检查正确性、未定义行为、生命周期、线程、热路径及 DDNet 协议/玩法/格式兼容。

- 仅列可说明触发条件和具体影响的缺陷，不把风格偏好或未验证猜想当 bug。
- 对历史兼容需求不确定时说明疑点，继续查真实代码；无法确认的项目单列待验证。
- 每项 finding 简述严重度、文件行号、触发与影响、最小修复建议。按严重度排序，格式随内容长度调整。
- `严重`：崩溃、数据丢失、安全或兼容性破坏；`重要`：真实功能 bug、生命周期或性能回退；`轻微`：低风险边界或维护问题。
- 没有确定缺陷就说明“未发现确定缺陷”，不能据此宣称代码完全正确。最后仅补相关验证和限制。

用户只要求审查时交付报告；已要求修复则验证候选后继续最小修改，既有授权无需再次确认。委托条件遵循根 `AGENTS.md`，验证范围遵循 `qmclient-verification-gate`。

普通 review 不自动加载深度质量模板；只有用户要求深度审计或问题确需系统性状态覆盖时使用 `audit-qmclient-quality`。
