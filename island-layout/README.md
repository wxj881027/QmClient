# 灵动岛编排台（island-layout）

一个零依赖的单文件网页，用来**在不改客户端代码的前提下**先摆一遍灵动岛里的内容。

直接双击 `index.html` 打开即可（`file://` 就行，不需要本地服务器）。

## 为什么这么做

苹果做对齐的路子是：先把形状糊掉，只在**大方向**上对齐（圆角、中线、内边距），
再把模糊去掉 —— 剩下的自然就是完全对齐的内容。

这个页面就是把这三步做成可操作的：
**① 先模糊 → ② 大方向对齐（圆角岛体）→ ③ 除去模糊**。

- **① 先模糊**：整岛连内容一起糊掉，只剩一个圆角剪影。这时候你看不见文字，只能看"块"和"方向"。
- **② 大方向对齐**：拖动元素，会自动吸附到岛体中线、元素中线/边缘、基准栅格（16px）上，
  并实时显示间距与吸附对象。
- **③ 除去模糊**：模糊撤掉，元素恢复清晰。此时报告会逐行判定"是否完全对齐"。

## 操作

| 操作 | 说明 |
| --- | --- |
| 拖动元素 | 移动位置，自动吸附（中线 / 边缘 / 间距 / 栅格） |
| 单击元素 | 选中，报告里会显示它的尺寸与坐标 |
| 方向键 | 微调 1px；`Shift` 5px；`Alt` 0.5px |
| 拖岛体左侧蓝色手柄 | 整岛平移 |
| `Ctrl` + `Z` | 撤销 |
| ◆ 一键解算对齐 | 自动跑完三步：模糊 → 吸附中线并重排间距 → 除模糊 |
| ◐ 模糊 / 清晰 | 手动切换模糊态 |
| ⤓ 存 PNG | 导出当前画面（2× 分辨率） |

## 报告怎么读

- `第 N 行 中线 … 偏差 0px 已对齐`：主行必须压在主行带中线上，偏差要 ≤0.5px。
- `主行上下留白 上 X 下 Y ✔ 居中`：顶部留白必须等于底部留白 —— 这是"看起来正"的关键。
- `底部行`：挂在主行带之下，间距规则是"主行带下沿 + 内边距"，不参与中线对齐。
- 元素之间的间距会标注 `/u=`，即相当于几个基准栅格（16px）。

## 三个预设

- **紧凑（现状）**：贴近当前客户端的排布 —— 左媒体胶囊 + 中央计时 + 右状态，底部挂歌词。
- **展开态**：带两枚卫星倒计时、标题/歌手两行、底部两条（歌词 + 换人请求）。
- **我流·两段式**：上排信息 + 下排歌词，用来试"两段式"这个方向。

## 和真实客户端的关系

页面尺寸抄的是 `src/game/client/components/hud.cpp` 里 `CHud::RenderMediaIsland()` 的几何：
设计缩放 `QmHudMediaIslandDesignScale = 0.8`，岛高 16×0.8、封面 12×0.8、内边距 2×0.8、
标题 5.8×0.8、底部行 7×0.8……

所以**页面里的像素数 ÷ 0.8 = 源码里的字面值**（报告底部也直接给了这个换算，例：栅格 16px = 源码字面 20）。
本页刻意只做视觉草图，不导出代码常量；真要把某个方案落到客户端，按这个换算改数值即可。

## 自检（可选，给自动化用）

`index.html` 支持两个调试入口，正常使用可以无视：

- URL 加 `#selftest`：跑一遍完整三步动画，并把量到的几何写进 `#dbg` 的 `data-*` 属性。
- URL 加 `#selftest-blur;preset=expanded`：直接进入模糊态，可指定 `compact` / `expanded` / `stacked`。

配合无头浏览器可以断言对齐结果：

```powershell
chrome --headless=new --dump-dom "file:///.../island-layout/index.html#selftest;preset=compact"
```
